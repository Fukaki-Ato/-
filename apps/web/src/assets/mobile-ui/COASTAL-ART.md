Originally generated with the authenticated Codex CLI `$imagegen`, without previous artwork as a reference. One 1024×1536 PNG draft, converted to WebP quality 87 (275,328 bytes). `coastal-frame.svg`, `coastal-shell.svg`, `coastal-corner.svg`, `coastal-wave.svg`: original hand-authored vector frame components. The frame is nine-sliced, preserving the rope and beveled rim thickness across responsive sizes; shells/starfish/waves are independent edge decorations. No generated replacement scenery is used. `coastal-pattern.svg` is also no longer used as a page background.
