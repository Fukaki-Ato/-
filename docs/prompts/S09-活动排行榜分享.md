## 任务清单

### 1. ActivitiesPanel（ui/panels/ActivitiesPanel.ts）

- 列表：`ctx.activity.list()` 渲染 Banner 卡（Banner 图占位降级、名称、时间范围、状态标签「进行中/未开始/已结束」、红点 `menu.activities`）。
- 详情：点击进入活动详情视图（同面板内切换或独立弹窗）：
  - 规则文本（`TextDialog` 或内嵌滚动）；
  - 里程碑列表：目标/进度条/奖励/领取按钮；`active` 才可领；`upcoming/ended` 显示状态文案；
  - 领取 → `ctx.activity.claim(id, index)` → RewardPopup；重复/过期失败的 reason 文案；
- 订阅 `activity.changed`、`currency.changed` 刷新；打开时 `ctx.activity.refreshIfNeeded()`。

### 2. LeaderboardPanel（ui/panels/LeaderboardPanel.ts）

- 页签：好友 / 世界；数据：`ctx.platform.cloud.getLeaderboard({board, top: 50})`。
  - 列表行：名次（前三特殊色）、头像（占位）、昵称、分数（`formatNumber`）；我的行高亮；
  - 顶部我的最佳成绩卡（来自 `me` 或 `stats.bestScore`）；
  - 状态：加载中（LoadingMask 或骨架文本）、空数据 EmptyState「暂无数据」、失败 Toast + 重试按钮；
  - `offline: true` 时显示「离线模式」小标签（Local 适配器会返回模拟数据，属预期）；
- 刷新按钮/下拉刷新（二选一，简单实现即可）。

### 3. 分享入口

- 结算面板的「炫耀一下」由 S08 在并行波次中实现，本会话不要修改结算面板与主界面。
- 不实现微信菜单转发（S10 统一处理 `onShareAppMessage`）。
