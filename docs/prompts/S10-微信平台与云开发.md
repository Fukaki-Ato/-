## 任务清单

### 1. 微信平台适配（assets/scripts/ui/platform/wechat/ 或 core/platform/wechat/）

> `wx` API 封装只允许出现在此目录；其余代码继续面向 `IPlatformAdapter`。

1. `WechatPlatformAdapter.ts`：实现 `IPlatformAdapter`，`kind='wechat'`：
   - `init()`：`wx.cloud.init({ env: cloudEnvId, traceUser: true })`（cloudEnvId 为空则不初始化云并降级）；`wx.showShareMenu({ withShareTicket: true })`；注册 `wx.onShareAppMessage` 统一文案；`wx.onShow/onHide` 回调通过构造注入交给 Boot（用于 `refreshDaily` 与 `flush`）；`wx.setKeepScreenOn`。
   - `storage`：wx 同步存储实现 `IStorage`。
   - `login()`：调用云函数 `login`（云环境已配置）获取 `{uid, nickname, avatarUrl}`；失败/未配置云 → 本地游客 uid 降级 + `isGuest=true`；昵称头像按 docs/05 §3 的「头像昵称填写能力」降级策略处理（实现基础版：默认昵称 + 空头像，UI 已有占位；进阶可选项写报告）。
   - `pay()`：Android `wx.requestMidasPayment`（参数从配置读取：offerId/env 等集中在 `app.json` 新增 `pay` 字段；未配置时返回 `unsupported`）；iOS 返回 `unsupported`。
   - `vibrate/copyText/setUserCloudStorage`：wx 对应 API（无则降级）。
2. `WechatAdService.ts`：实现 `IAdService`；按 placement 映射 adUnitId（`app.json` 新增 `adUnits: { 'settlement.double': '', ... }`，空串走模拟逻辑保持可测）；`wx.createRewardedVideoAd` 实例缓存、`preload`、`show` Promise 化（onClose: `isEnded` 决定 completed；onError 预加载重试 + 失败返回 `{completed:false}`）；预加载在 Boot 后调用一次。
3. `WechatCloudService.ts`：实现 `ICloudService`；`wx.cloud.callFunction` 封装；`uploadSave/downloadSave` 对应 `syncSave`；`submitScore`/`getLeaderboard` 对应云函数；超时与错误处理（返回安全默认值，不抛到 UI）。
4. Boot 调整：平台选择逻辑 `typeof wx !== 'undefined'` 且云配置存在 → WeChat，否则 Local；隐私流程改为 `wx.getPrivacySetting` + `wx.onNeedPrivacyAuthorization`（或 `wx.requirePrivacyAuthorize`），未同意不登录；`wx.onShow` → `ctx.refreshDaily()`，`wx.onHide` → `ctx.flush()`；`createUserInfoButton`/头像昵称能力如采用需截图说明。

### 2. 云开发（cloudfunctions/）

按 docs/05 §4 创建：`login`、`syncSave`、`submitScore`、`getLeaderboard`（Node.js + `wx-server-sdk`，含各自 `package.json` 与最小 `config.json` 权限配置如有需要）；公共代码可放 `cloudfunctions/common/`（README 说明部署时同步）。要求：

- 输入校验（分数范围、字段类型）与错误码；
- `getLeaderboard` 返回 `{ list, me }` 与契约一致（`rank` 从 1 开始）；
