### 2. 核心框架（assets/scripts/core/framework/）

按 `contracts.ts` 实现，文件建议一文件一模块：

- `Logger.ts`：实现 `ILogger`；输出前缀 `[LTKP]`；`debug` 由 `enabled` 开关控制（默认 false，Boot 阶段按 app.json 打开）。
- `EventBus.ts`：实现 `IEventBus`；emit 遍历监听副本（回调中增删监听不影响本次派发）；单个回调异常捕获后继续派发其余回调并 error 日志；支持 `offTarget` 与 `once`。
- `Clock.ts`：实现 `IClock`；构造可注入 `now()` 与 `resetHour`；`dateString` 输出本地时区 `YYYY-MM-DD`；`gameDay` = 将时间戳减去 `resetHour` 小时后取日期；`weekKey` 按周一为一周起点，同一周内所有日期返回相同 key（格式如 `2026-W40`，具体算法自定，测试用「周一/周日同 key、跨周不同」断言）。
- `Storage.ts`：`MemoryStorage`（Map 实现）与 `createSafeStorage()`（探测顺序 `wx.getStorageSync` → `localStorage` → 内存；宿主探测只允许 `typeof` 判断且封装在本文件内）。
- `SaveRepository.ts`：`createDefaultSave(profile, gameDay, weekKey)` 工厂（默认角色 `runner_default` 已解锁并选中、等级 1，货币与道具为空，`version = SAVE_VERSION`）；`LocalSaveRepository implements ISaveRepository`（构造注入 `storage/clock/log`）：load 解析失败或结构校验失败时备份到 `ltkp.save.corrupt.<ts>` 并返回默认档；`data.version > SAVE_VERSION` 视为不可用（备份 + 默认档）；`migrations: Record<number, (old: any) => any>` 逐版本迁移（本次 v1 无实际迁移，留机制与单测）。
- `Utils.ts`：`clamp/toInt/formatNumber(≥1万→"x.x万"，≥1亿→"x.x亿")/safeJsonParse`。

### 3. 本地平台适配（assets/scripts/core/platform/）

- `LocalPlatformAdapter.ts`：实现 `IPlatformAdapter`，`kind='local'`；
  - `login()`：首次生成 `guest_<8位随机>` 存 `ltkp.local.uid` 并复用；返回 `{ uid, nickname: '酷跑玩家', avatarUrl: '', isGuest: true }`；
  - `ad`：`MockAdService`，支持构造配置 `completed` 结果与延迟（默认 800ms），`isReady` 恒 true，`preload` 空实现；
  - `cloud`：`LocalCloudService`（同目录）：`init` 空、`uploadSave/downloadSave` 用 storage 键 `ltkp.cloud.save` 模拟、`submitScore` 记录本地最佳并返回 `{ok:true,bestScore,rank:1}`、`getLeaderboard` 生成稳定假数据（10 条，含 `me`，`offline: true`）；
  - `share` 返回 true 并日志；`pay` 返回 `{ok:false, reason:'unsupported'}`；`copyText/vibrate/setUserCloudStorage` 为日志/空实现。
- `LocalCloudService.ts` 独立文件便于单测。

### 4. Mock 玩法（assets/scripts/core/gameplay/MockGameplayLauncher.ts）

实现 `IGameplayLauncher`：`isMock=true`；`preload()` 立即完成；`launch(opts)` 按构造注入的 `delayMs`（默认 2500）与 `random`（默认 Math.random）生成结果：
`score = 300 + floor(r*2700)`、`distance = 200 + floor(r*1000)`、`coins = 20 + floor(r*280)`、`diamonds = r<0.5 ? 0 : 1+floor(r*2)`、`durationMs = 60000 + floor(r*60000)`、`revivedCount = 0`、`mode = opts.mode`。

### 5. 测试（tests/）

镜像目录：`tests/framework/*.test.ts`、`tests/platform/*.test.ts`、`tests/gameplay/*.test.ts`。必须覆盖：

- EventBus：on/off/once/offTarget、回调抛错不影响后续、emit 中增删监听；
- Clock：`gameDay` 在 resetHour 前后边界（如 resetHour=0 与 =5 两组用例）、weekKey 周一/周日同 key、跨周不同；
- SaveRepository：读写往返、损坏 JSON 恢复并生成备份键、更高版本号走默认档、迁移函数被调用（构造 v0 档验证升级到 v1）；
- LocalPlatformAdapter：登录 uid 跨实例稳定、广告模拟结果可配置、排行榜结构合法；
- MockGameplayLauncher：结果字段范围与非负整数、delayMs=0 时立即返回。
