## 任务清单

### 1. ShopPanel（ui/panels/ShopPanel.ts）

- 页签：金币/钻石/道具/特惠（`ShopTab`）；每个页签用 `GridList` 渲染 `ctx.shop.list(tab)`。
- 商品卡：图标（占位降级）、名称、描述、价格区（金币/钻石图标+数值、「免费」、「¥x.xx」）、限购角标（`remainingDaily`）、售罄/锁定置灰、`tag` 标签。
- 购买流程：
  1. ConfirmDialog 确认（含价格与获得内容）；
  2. `const r = ctx.shop.buy(id)`：
     - `r.needAd` → LoadingMask + `ctx.platform.ad.show('shop.free.gold')`；completed → `ctx.shop.claimAd(id)` → RewardPopup；取消 → Toast「看完视频才能领取」；
     - `r.needPay` → `ctx.platform.pay({id: r.needPay.productId, priceFen: r.needPay.priceFen})`；ok → `ctx.shop.claimPay(id)` + RewardPopup；cancel/unsupported → Toast；
     - `r.ok` → RewardPopup(`ctx.reward.describe(r.reward)`)；
     - 失败 → 按 `reason` 文案 Toast（insufficient 时按钮「去赚金币」切到金币页签）。
- 平台规则：`kind === 'wechat'` 且平台为 iOS 时隐藏 `iosVisible=false` 的商品；iOS 判断接口当前未提供时，先在 `IPlatformAdapter` 外做本地函数占位并留 TODO（不得改契约），报告说明。
- 注意：打开面板时先 `ctx.shop.refreshIfNeeded()`；订阅 `shop.changed`/`currency.changed` 刷新列表与货币栏。

### 2. WarehousePanel（ui/panels/WarehousePanel.ts）+ ItemDetailPopup

- 页签：全部/道具/材料；数据来自 `ctx.inventory.all()` + `ConfigService.item()`；数量为 0 的条目不显示（空态 EmptyState）。
- 品质边框色用 `Theme`；数量角标用 `formatNumber`。
- ItemDetailPopup：图标、名称、品质、描述、用途文案（如「下局生效」）、按钮：
  - `useTargets` 含 `'menu'` 且有 useEffect → 「使用」→ `ctx.useItem(id)`→ 成功 RewardPopup/Toast（runBuff 提示「已激活，下局生效」）；失败按 reason；
  - 仅 `'run'` → 按钮禁用，文案「局内使用」；
  - 无 effect（材料）→ 显示「材料」，无按钮。
- 使用后订阅 `inventory.changed` 刷新。

### 3. CharactersPanel（ui/panels/CharactersPanel.ts）

- 列表：`ctx.character.list()`；卡片显示头像占位、名称、品质、状态（已选/未解锁/已拥有 Lv.x）。
- 详情：大图（占位）、描述、属性行（速度/跳跃/磁铁/金币加成）、等级；按钮按状态：
  - 未解锁 → 「解锁」（货币/道具显示费用；条件类型显示锁定原因）；
  - 已解锁未满级 → 「升级」（显示费用与下一级预览）；
  - 已选 → 置灰「使用中」；其他已解锁 → 「使用」；
- 操作统一走 `ctx.character.unlock/upgrade/select`，成功 Toast/动效（简单缩放即可），失败按 reason（insufficient → 「金币不足」等）；订阅 `character.changed` 刷新。
- 红点 `menu.characters` 由 core 规则决定，面板内不自行计算。
