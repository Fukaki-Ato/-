## 任务清单

### 1. WelfarePanel（ui/panels/WelfarePanel.ts）

- 页签：签到 / 每日福利。
- 签到页：`ctx.welfare.signInState()` 渲染 7 日奖励格：
  - 三态样式（已领/今日可领高亮/未来灰）；
  - 顶部显示当前周期说明；「立即签到」按钮点击 → `ctx.welfare.signIn()` → RewardPopup + 刷新；
  - 已签到时按钮置灰「明日再来」。
- 每日福利页：每日免费金币卡（`dailyFreeAdClaimed()` 状态）→ 看视频领取：`ctx.platform.ad.show('welfare.daily')` → completed → `ctx.welfare.claimDailyFreeAd()` → RewardPopup；取消 Toast。
- 订阅 `welfare.changed`/`day.changed` 刷新；红点由 `RedDots.bind(node,'menu.welfare')`。

### 2. TasksPanel（ui/panels/TasksPanel.ts）

- 页签：每日 / 每周；`RowList` 渲染 `ctx.task.list(type)`：
  - 行：名称+描述、进度文本 `x/y` + 进度条、奖励预览（图标+数量，可点击查看 RewardPopup 详情）、右侧按钮（`去完成`[link]/`领取`[claimable]/`已领取`[灰]）；
  - 顶部「一键领取」：无 claimable 置灰；点击 → `claimAll(type)` → RewardPopup(汇总) + Toast；
  - `link` 跳转：run→关闭面板（由 S08 处理开始跑酷，先 Toast 提示）、shop→打开 Shop、character→打开 Characters、welfare→Welfare、none→无跳转；跳转用 `PanelManager.open/close`。
- 订阅 `task.changed`、`day.changed` 刷新；红点 `menu.tasks`。
- 空列表用 EmptyState。

### 3. AchievementsPanel（ui/panels/AchievementsPanel.ts）

- `RowList` 渲染 `ctx.achievement.list()`：勋章占位图、名称、描述、进度条、奖励、领取按钮（同任务风格）。
- 领取 → `ctx.achievement.claim(id)` → RewardPopup；订阅 `achievement.changed`；红点 `menu.achievements`。

### 4. 通用要求与提交

- 领取按钮防连点（操作期间禁用，完成或失败后恢复）；所有金额/数量显示用 `formatNumber`。
