## 任务清单

### 1. 启动流程（assets/scripts/ui/boot/）

1. `GameRoot.ts`（组件）：挂到场景节点后初始化 UIRoot；创建平台适配器工厂 `createPlatformAdapter(ctx?)`：当前仅 Local（环境探测与 WeChat 分支留 `// S10` 注释与 TODO，不得实现 wx 代码）；构造 `CocosConfigSource`（用 `resources.load` 加载 `config/*.json`，实现 `IConfigSource`）；`createGameContext`。
2. `Boot.ts`（组件，场景挂载点）：
   - 显示 Logo/加载文本/版本号（左下，版本取 app.json）；
   - 隐私授权：`flags.privacyAccepted` 为 false 时用 `TextDialog + ConfirmDialog` 展示 `privacyPolicy` 摘要与「同意并继续/暂不同意」；不同意则停留在启动页（可再次查看协议）；
   - 登录：`platform.login()`，失败降级并 Toast「游客模式」；登录结果写 `save.profile`（uid 不同则视为新设备：仅更新 profile，不覆盖存档）；
   - `ctx.refreshDaily()`、`AudioService.playBgm('audio/bgm/main')`（BGM 延后到主界面打开）；
   - `PanelManager.open('MainMenu')`；启动失败（配置校验异常）显示错误文本 + 重试按钮。
3. 场景：尝试生成 `assets/scenes/Main.scene`（最小合法 JSON：Canvas + 挂 Boot 的节点 + 相机）。若无法保证合法，**不要强行提交坏场景**：在报告写明手动创建步骤（docs/08 §3 已有），并在 `docs/08` 对应位置补一行「S05 结果：自动/手动」。
4. 调试能力（仅 `app.json.debug=true` 生效）：长按版本号 2 秒打开简易调试面板：+1000 金币、+100 钻石、清空存档、当前游戏日显示（用于人工冒烟）。

### 2. 主界面（assets/scripts/ui/panels/MainMenuPanel.ts）

对照界面截图与 docs/04 §3.2：

- 顶部：金币/钻石 + `+`（打开商店对应页签，S06 前先 Toast「商店开发中」）→ `CurrencyBar`；右上齿轮 → Settings。
- 左上：活动（喇叭）、任务（卷轴）；右上：成就（勋章）、排行榜（奖杯）→ 打开对应面板名（`Activities/Tasks/Achievements/Leaderboard`，未注册时 Toast「开发中」且不崩溃）。
- 中央：开始酷跑按钮（占位金底圆角+文字）；`debug` 模式下显示「沙盒模式」角标；点击逻辑：调用 `ctx.gameplay.launch({ mode:'classic', characterId: ctx.save.characters.selected })` 并 Toast 展示结果（S08 实现完整结算接入，本会话先用 LoadingMask + 结果 Toast 占位，代码留清晰接入点）。
- 底部：商店/福利手册/仓库/角色四入口（面板名 `Shop/Welfare/Warehouse/Characters`）。
- 所有入口红点：按 docs/02 §4 的 key 用 `RedDots.bind`。
- 背景：`images/bg/main`（缺失走占位渐变/色块）；界面元素一律经 `Assets` 工具。

### 3. 设置面板（assets/scripts/ui/panels/SettingsPanel.ts）

按 docs/04 §3.3：音乐/音效开关（AudioService + 存档）、隐私政策、用户协议、联系客服（有配置则 `platform.copyText` 并 Toast，无配置隐藏）、重置存档（ConfirmDialog 二次确认 → `repo.reset` 语义：通过 `ctx` 暴露的方式或直接清 storage 后重启回 Boot，按现有 API 选择最小实现并写报告）、版本号、返回按钮。
