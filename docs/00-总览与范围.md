# 00 总览与范围

## 1. 项目目标

开发一款可上架微信小游戏的跑酷游戏「雷霆酷跑」。本次协作的目标是完成**除跑酷玩法本体之外的全部功能**：启动流程、主界面、货币经济、商店、仓库、角色养成、福利、任务、成就、活动、排行榜、设置、结算、平台与云开发接入，并为跑酷玩法留出标准接口。

## 2. 产品形态与技术决策（已确认）

| 决策项 | 结论 | 说明 |
| --- | --- | --- |
| 发布形态 | 微信小游戏 | 含游戏内容必须走小游戏类目，避免审核驳回 |
| 引擎 | Cocos Creator 3.8.x + TypeScript | 跑酷品类主流方案，小游戏导出成熟 |
| 后端 | 微信云开发（云函数 + 云数据库） | 首版允许本地模式运行，云能力按适配层接入 |
| 美术 | 素材后置，开发期程序化占位 | 所有界面在素材缺失时必须可运行、可验收 |
| 玩法边界 | 独立模块，先接口 + Mock | `IGameplayLauncher` 协议见 docs/06 |

## 3. 功能范围

### 3.1 范围内（本次协作交付）

1. 启动流程：加载、隐私授权、登录（微信/游客）、跨天检查
2. 主界面：货币栏、设置、活动/任务/成就/排行榜入口、开始酷跑、底部四入口
3. 经济系统：金币、钻石、道具；获取/消耗/流水事件
4. 商店：分类页签、限购、广告免费商品、购买确认、充值入口（iOS 规则）
5. 仓库：道具列表、详情、使用/消耗
6. 角色：解锁、升级、选择、属性计算
7. 福利手册：7 日签到、每日免费广告奖励
8. 任务：每日/每周任务、进度追踪、领取、一键领取
9. 成就：进度、领取
10. 活动：配置驱动的时间段活动、里程碑领取
11. 排行榜：好友榜（开放数据域）/世界榜（云）
12. 设置：音乐/音效、隐私政策、用户协议、联系客服、版本信息
13. 跑酷入口与结算：进入协议、Mock 实现、结算与广告翻倍
14. 平台适配：本地适配器（开发/测试） + 微信适配器（小游戏真机）
15. 云开发：登录、云存档、排行榜云函数与集合
16. 红点系统、音频管理、通用弹窗/提示/奖励弹窗
17. 工程基建：单元测试、类型检查、文档与验收流程

### 3.2 范围外（不由本次协作负责）

- 跑酷玩法本体：操作、关卡生成、物理碰撞、镜头、局内 UI、局内数值与复活实现
- 美术资源制作（用户后置提供，工程内已定义路径规范与占位降级）
- 微信开放平台注册、类目申请、软著/版号等资质流程
- 实名认证与防沉迷（由微信平台提供能力，接入点已在 docs/05 标注）
- 数据统计平台（预留埋点函数 `trackEvent`，不接第三方 SDK）

## 5. 角色与协作模式

| 角色 | 职责 |
| --- | --- |
| 用户 | 派发子会话、传递验收结论、提供素材与环境 |
| 主会话（方案负责人） | 架构与契约设计、撰写子会话提示词、逐会话验收、最终集成验收 |
| 子会话 S01–S10 | 按提示词实现各自模块、跑测试、写报告、提交 git |

**派发原则**：一次只派发一个子会话，完成后回到主会话验收，再派发下一个。详见 docs/09。

## 6. 完成定义（DoD）

单个子会话视为完成，需同时满足：

1. 交付物齐全，且不破坏既有公共契约（`assets/scripts/core/contracts.ts`）；
2. `npm run check` 全绿（涉及 core 的会话）；`npm run typecheck:cc` 通过（涉及 UI 的会话）；
3. 按 `docs/07` 中对应验收清单自检并在报告逐条标注；
4. 新增/修改文件已 git 提交，提交信息以会话号开头（如 `S05: 主界面与设置`）；
5. 撰写 `docs/reports/SXX-*.md`，包含：改动清单、测试结果、遗留问题、需要人工在编辑器/真机验证的事项。

## 7. 名词表

| 术语 | 含义 |
| --- | --- |
| 核心层 core | 纯 TypeScript，不依赖 Cocos 与微信 API，可被 Node/Vitest 直接测试 |
| 界面层 ui | 依赖 `cc` 的 Cocos 代码，纯代码构建界面，不使用 Prefab |
| 占位降级 | 资源缺失时用程序绘制（色块/圆角/文字）替代，保证不崩溃 |
| 游戏日 gameDay | 计入每日重置时刻（默认 00:00）后的日期，见 docs/02 |
| 结算 | 一局跑酷结束后计算并发放奖励的流程 |
| 契约 | `core/contracts.ts` 中的公共类型与服务接口，唯一事实来源 |

## 8. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 本机暂未安装 Cocos/微信开发者工具 | UI 无法运行预览 | docs/08 提供安装步骤；先以类型检查 + core 单测推进，安装后逐会话补冒烟 |
| Cocos 场景文件手工生成易出错 | 无法进入游戏 | 启动逻辑纯代码化；场景仅需一个挂载 Boot 的空场景，文档给出编辑器手动步骤兜底 |
| 子会话间接口漂移 | 集成失败 | contracts.ts 唯一事实来源 + 每会话 `npm run check` + 主会话验收 |
| 素材后置导致布局返工 | 返工成本 | 占位与真图同路径、同锚点；资源清单先定（docs/04） |
| 云开发额度/审核要求变化 | 上线受限 | 适配层隔离；首版本地可跑；云配置集中 app.json（docs/05） |
| iOS 虚拟支付限制 | 充值不可用 | 商店充值页按平台隐藏，Android 走米大师，见 docs/05 |
