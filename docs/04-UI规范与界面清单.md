# 04 UI 规范与界面清单

## 1. 基础设定

| 项 | 规范 |
| --- | --- |
| 设计分辨率 | 750 × 1624（竖屏），Fit Width，Widget 锚定 |
| 安全区 | 顶部货币栏与底部导航使用 SafeArea/Widget 约束，适配刘海屏与手势条 |
| 色调 | 沙滩夏日风：天蓝 #4EC3F7、沙黄 #F5D07A、木棕 #7A4A2B、金币 #FFC53D、钻石 #5AD2F4、红点 #FF4D4F |
| 字体 | 系统字体，主标题 40–56，按钮 32–36，正文 26–30，辅助 22–24 |
| 层级 | Scene(0) / Panel(100) / Popup(200) / Toast(400) / Loading(500) / Debug(900) |
| 面板动效 | 打开：缩放 0.92→1 + 透明度 0→1（0.18s）；关闭反向。弹窗从中心缩放 |
| 音效钩子 | 按钮/页签点击 `sfx/click`，领取/购买成功 `sfx/reward`，失败 `sfx/error`（资源缺失静默） |
| 输入 | 打开 Popup/Loading 时拦截下层点击（BlockInputEvents）；面板打开期间主界面按钮不可点 |

## 2. UI 基座（S04 交付）

`assets/scripts/ui/framework/` 组成：

| 模块 | 职责 | 主要 API |
| --- | --- | --- |
| UIRoot | Canvas 与分层节点、适配、Resize 处理 | `UIRoot.getLayer(layer)` |
| PanelManager | 面板注册/打开/关闭/返回、弹窗队列、动画、互斥 | `register(name, ctor)` `open(name, data?)` `close()` `closeAll()` |
| BasePanel / BasePopup | 生命周期 `onCreate/onOpen/onClose/onCover`；`onCreate` 中纯代码建树 | 抽象类 |
| Theme | 颜色/字号/间距/圆角/品质色 tokens | 常量对象 |
| Assets | 资源加载与**占位降级**（Graphics 圆角块+首字），失败仅告警一次 | `sprite(node, path, opts)` `label(node, text, opts)` |
| UIKit | 创建常用节点：按钮、文本、列表、进度条、页签、开关、遮罩 | 工厂函数 |
| RedDots | 绑定红点 key 到节点，自动订阅 `reddot.changed` | `RedDots.bind(node, key)` |
| AudioService | BGM/SFX 播放、开关联动存档 settings、缺资源静默 | `playBgm(path)` `playSfx(path)` `setMusic(bool)` |
| Toast | 轻提示（2s 自动消失，队列上限 3） | `Toast.show(text)` |
| ConfirmDialog | 确认/取消，Promise 返回 | `ConfirmDialog.show({title, content})` |
| RewardPopup | 奖励展示（图标+数量+名称），支持"双倍领取"按钮回调 | `RewardPopup.show(reward, opts?)` |
| LoadingMask | 全屏遮罩+菊花，可加文本 | `LoadingMask.show(text?)` `hide()` |
| GridList / RowList | 代码创建单元、支持空态、数据较少时一次性创建（≤ 120 单元） | `grid.setData(items, render)` |
| CurrencyBar | 金币/钻石图标+数量+加号，订阅 `currency.changed` | `new CurrencyBar(node, ctx)` |
| EmptyState | 缺省插画+文案（占位图） | `EmptyState.show(node, text)` |
| TextDialog | 长文本弹窗（隐私政策/用户协议/活动规则） | `TextDialog.show({title, text})` |

**占位降级规则**：`Assets.sprite` 加载 `resources/<path>` 失败时，绘制与目标同尺寸的圆角矩形（颜色取自 opts 或调色板）+ 可选首字文本；不得抛异常、不得空白节点。素材就位后仅放文件即可生效。

## 3. 界面清单（逐面板规格）

> 每个面板的"验收点"是主会话验收时逐条核对的最小集合。

### 3.1 Boot（启动）— S05

- 元素：Logo/游戏名、加载进度文本、版本号（左下）。
- 交互：初始化 context → 隐私授权（若 `flags.privacyAccepted` 为假先弹政策确认）→ 登录（失败降级游客）→ 载入配置/存档 → `refreshDaily` → 打开 MainMenu。
- 状态：加载失败（配置校验失败）展示错误文本并允许重试。
- 验收点：本地模式可完整进入主界面；重复启动不重复发新手资源；跨天重启触发 `day.changed`。

### 3.2 MainMenu（主界面，对应截图）— S05

- 顶部：金币（图标+数量+`+`→商店金币页）、钻石（同）、右上齿轮→设置。
- 左上：活动（喇叭）、任务（卷轴）竖排；右上：成就（勋章）、排行榜（奖杯）竖排；均带红点。
- 中央：开始酷跑大按钮（占位为圆角金底+文字）；下方预留角色/装饰位。
- 底部：商店 / 福利手册 / 仓库 / 角色 四入口（图标+文字，均带红点规则中对应的 key）。
- 背景：`images/bg/main` 全屏，缺失时天空渐变+沙滩色块占位。
- 交互：点击入口打开对应面板（未实现的面板给出"开发中"Toast，不得崩溃）；沙盒模式下开始按钮进入 Mock 跑酷与结算。
- 验收点：与截图元素一一对应；红点随数据变化；返回主界面时货币实时刷新。

### 3.3 Settings（设置）— S05

- 元素：音乐开关、音效开关、隐私政策（TextDialog）、用户协议（TextDialog）、联系客服（复制客服 QQ/微信号并 Toast）、重置存档（二次确认，清空后回到 Boot）、版本号。
- 验收点：开关即时生效且持久化；文案来自 app.json；重置后存档回到默认值。

### 3.4 Shop（商店）— S06

- 顶部：货币栏。页签：金币 / 钻石 / 道具 / 特惠。
- 商品卡：图标、名称、描述、价格（货币图标+数值 / "免费" / "¥6"）、限购角标（"今日 2/3"）、售罄/锁定置灰。
- 交互：点击购买→ConfirmDialog→成功走 RewardPopup；失败按 reason Toast（余额不足时提供"去充值/去赚金币"跳转对应页签）；广告商品显示"看视频"按钮，广告成功回调后发货。
- 规则：`iosVisible=false` 的 CNY 商品在 iOS 隐藏；每日限购跨天刷新。
- 验收点：四种页签渲染；购买扣费与发货原子；限购、售罄、余额不足、广告取消均正确处理。

### 3.5 Warehouse（仓库）— S06

- 页签：全部 / 道具 / 材料。
- 道具格：图标+数量角标+名称（品质边框色）；点击打开 ItemDetailPopup：图标、名称、描述、用途、按钮（使用/不可用原因）。
- 使用：`useTargets` 含 `menu` 且效果为 `runBuff` 时提示"下局生效"（真正生效在 S08 与玩法对接）；为 `grant` 时立即发放。
- 验收点：空态展示；数量为 0 的道具不显示（或置灰，取一致行为并写明）；使用后数量与事件正确。

### 3.6 Characters（角色）— S06

- 布局：左侧角色卡列表（头像、名称、品质、状态：已选/已解锁/未解锁），右侧/底部详情区（大图占位、描述、属性条：速度/跳跃/磁铁/金币加成、等级 Lv.x）。
- 按钮：选为当前 / 解锁（显示价格）/ 升级（显示费用与下一级属性预览）/ 已满级。
- 规则：解锁/升级走将金币/钻石/条件；选择立即生效并持久化；属性变化小提示。
- 验收点：解锁、升级、选择全流程；资源不足禁用并提示；默认角色不可重复解锁。

### 3.7 Welfare（福利手册）— S07

- 页签：签到 / 每日福利。
- 签到：7 日奖励格（已领/今日可领/未来三态），今日可领格高亮；领取后飞奖励弹窗并推进周期；跨天刷新；第 7 天领完回到第 1 天。
- 每日福利：免费金币（看广告），当日已领置灰。
- 验收点：签到幂等；周期推进正确；红点 `menu.welfare` 联动。

### 3.8 Tasks（任务）— S07

- 页签：每日 / 每周；列表行：名称+描述、进度条 x/y、奖励预览、按钮（去完成/领取/已领取）。
- 底部/顶部："一键领取"（无奖励时置灰）。
- 规则：进度事件驱动即时刷新；每日/每周按游戏日/周重置；"去完成"按 `link` 跳转（跑酷/商店/角色等）。
- 验收点：跑一局后进度增加；领取与一键领取正确累加；重置逻辑正确。

### 3.9 Achievements（成就）— S07

- 列表：勋章占位图、名称、描述、进度条、奖励、领取按钮。
- 验收点：进度随行为推进；领取后红点消失。

### 3.10 Activities（活动）— S09

- 列表：Banner 卡（名称、时间范围、状态标签：进行中/未开始/已结束、红点）。
- 详情：规则文本（TextDialog 或内嵌）、里程碑列表（进度、奖励、领取按钮）。
- 验收点：时间窗状态正确；里程碑领取幂等；未开始/已结束活动不可领取。

### 3.11 Leaderboard（排行榜）— S09/S10

- 页签：好友 / 世界；列表行：名次、头像（占位）、昵称、分数；顶部我的最佳成绩卡（名次、分数）。
- 状态：加载中/为空（本地模式显示模拟数据与"离线模式"标记）/失败重试。
- 验收点：两种榜单切换；刷新；异常态不崩溃。

### 3.12 RunSettlement（结算）— S08

- 元素：标题"结算"、分数（大号）、距离、金币拾取数、奖励列表（基础金币/钻石/掉落道具）、按钮：双倍领取（广告，仅一次）/ 直接领取 / 再来一局。
- 流程：进入时展示 LoadingMask（等待结算计算）→ 展示基础奖励 → 双倍领取成功后展示 RewardPopup，直接领取不弹窗（奖励已在面板列表明示）→ 返回主界面并刷新红点。
- 验收点：双倍仅一次且只能通过广告；领取幂等（快速连点不重复发货）；未领取直接返回时奖励不发放（或自动发放，二选一并在实现中保持全局一致——默认自动发放基础奖励，双倍为可选）。

## 4. 资源规范（素材后置）

### 4.1 路径与命名

- 全部资源位于 `assets/resources/`，加载路径不带扩展名，如 `resources.load('images/ui/btn_start')`。
- 目录：`images/bg`、`images/ui`、`images/items`、`images/characters`、`audio/bgm`、`audio/sfx`。
- 命名：小写蛇形 `类型_对象[_状态]`，例：`btn_start`、`icon_gold`、`panel_common`、`char_runner_default`。
- 同一路径只放一个文件（png/jpg 由引擎解析），替换素材保持文件名不变。
- 建议透明 PNG 使用 2x 尺寸导出；全屏背景 750×1624 起。

## 5. 手测冒烟清单（编辑器可用后）

1. 启动进入主界面，货币与截图一致（本地新档 0/0，可通过调试指令发币）。
2. 主界面每个入口可打开/关闭，红点符合规则。
3. 购买金币、看广告领免费金币、钻石充值入口（iOS 隐藏）。
4. 仓库使用道具、角色解锁升级选择。
5. 签到 7 天逻辑（可用调试改系统时间或注入 Clock 验证）。
6. 任务进度随跑酷结果更新、领取、一键领取、跨天重置。
7. 开始酷跑 → Mock 结算 → 双倍广告 → 返回主界面。
8. 活动时间窗、排行榜切换、设置开关、重置存档。
