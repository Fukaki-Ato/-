# 10 微信配置清单（S10）

> 本文是「雷霆酷跑」上线微信小游戏需要用户在**微信公众平台 / 微信开发者工具 / 云开发控制台**完成的事项总表。
> 仓库内所有配置均为**占位符**（空串/示例值），禁止提交真实 AppID、环境 ID、广告位 ID、支付参数与密钥。

## 1. 账号与基础信息

| # | 事项 | 入口 | 说明 |
| --- | --- | --- | --- |
| 1.1 | 小游戏 AppID | 微信公众平台 → 设置 → 基本设置 | 填入 Cocos 构建面板 AppID 与 `project.config.json`；仓库不记录真实值 |
| 1.2 | 游戏名称/图标/简介 | 微信公众平台 → 设置 | 与启动页/分享文案保持一致 |
| 1.3 | 服务类目 | 微信公众平台 → 设置 → 基本设置 → 服务类目 | 选择游戏类目；类目影响虚拟支付与广告开通资格 |
| 1.4 | 资质材料 | 微信公众平台 → 设置 | 软著/版号/主体资质按平台要求提交（国内游戏类目通常需要） |
| 1.5 | 服务器域名 | 微信公众平台 → 开发 → 开发设置 | 云开发无需配置；如后续接自建后端再配置 request 合法域名 |

## 3. 广告（激励视频）

| placement | 触发场景 | 后台入口 | 配置字段 |
| --- | --- | --- | --- |
| `settlement.double` | 结算双倍领取 | 微信公众平台 → 流量主 → 广告位管理 | `app.json` → `adUnits['settlement.double']` |
| `shop.free.gold` | 商店广告免费商品 | 同上 | `adUnits['shop.free.gold']` |
| `welfare.daily` | 福利每日免费奖励 | 同上 | `adUnits['welfare.daily']` |
| `run.revive` | 局内复活（预留） | 同上 | `adUnits['run.revive']` |

- 广告位类型选择**激励视频**；空串时游戏走模拟逻辑（可交付/可取消），未配置也能完整体验流程；
- 开量前确认已满足流量主开通条件（累计独立访客等平台要求）；
- 注意合规：不得以误导方式诱导观看，失败/未看完不发奖（代码已处理）。

## 4. 虚拟支付（Android 米大师）

| # | 事项 | 入口 | 说明 |
| --- | --- | --- | --- |
| 4.1 | 虚拟支付进件/开通 | 微信公众平台 → 虚拟支付 | 按平台指引完成进件 |
| 4.2 | 获取 offerId / zoneId | 米大师（虚拟支付）后台 | 填入 `app.json` → `pay.offerId` / `pay.zoneId`；沙箱联调用 `pay.env=1` |
| 4.3 | 商品映射 | `assets/resources/config/shop.json` | `price.currency='CNY'` 商品的 `productId` 必须与米大师道具（goods）配置一致（validate 已强制非空） |
| 4.4 | iOS 规则 | 无后台操作 | iOS 隐藏 CNY 商品（`iosVisible` 规则）；`platform.pay` 对非 Android 返回 `unsupported` |
| 4.5 | 服务端校验（后续加固） | 自建后端/云函数 | 当前版本以米大师客户端回调发放奖励；正式运营建议接入服务端支付回调校验与补单，防重放 |

最小可用方案：客户端 `wx.requestMidasPayment` 成功 → `ShopService.claimPay` 发放 `gain`。
加固建议：增加订单号、服务端校验米大师账单、失败补偿队列（超出 S10 范围，已在报告遗留问题登记）。

## 7. 体验版与提审

1. 构建 `debug=false`、`md5Cache=true`（提审包）；
2. （可选好友榜）执行 `npm run wechat:opendata`；
3. 微信开发者工具 → 上传代码 → 填写版本号与备注；
4. 微信公众平台 → 版本管理 → 设为体验版 → 扫码真机回归（docs/08 §4.6）；
5. 提审前自查（对照 docs/07 §3 与本文 §5）：
   - 隐私弹窗在未同意时不登录、不读取用户信息；
   - iOS 无充值入口、无「充值」字样诱导；
   - 广告完整观看才发奖，可取消且按钮恢复；
   - 无外链、无诱导分享、未成年人提示与适龄提示齐全；
   - 云环境与云函数为正式环境，占位文本全部替换。

## 9. 安全注意

- 本仓库禁止提交任何真实 ID/密钥；`.gitignore` 已忽略构建产物与云函数公共代码副本；
- 云函数全部经 `cloud.getWXContext().OPENID` 识别用户，客户端不直连数据库；
- `submitScore` 对分数/距离/文本做范围与长度校验；`syncSave` 校验版本与大小并防止旧档覆盖；
- 后续接入服务端支付校验时，验签密钥只存服务端，不得下发客户端。
