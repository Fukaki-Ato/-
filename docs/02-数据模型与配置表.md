# 02 数据模型与配置表

> 类型定义的唯一事实来源是 `assets/scripts/core/contracts.ts`。本文件解释设计意图与规则；如两者冲突，以 contracts.ts 为准并以 PR/会话报告修正文档。

## 1. 存档（SaveData）

### 1.1 存储键与迁移

| 项 | 规则 |
| --- | --- |
| 存储键 | `ltkp.save.v1`（`SAVE_KEY`，定义于 framework/SaveRepository） |
| 版本号 | `SAVE_VERSION = 1`，`save.version` 不匹配时依次执行迁移函数 |
| 迁移函数 | `migrations: Record<number, (old: any) => any>`，逐版本升级，禁止跳级 |
| 损坏处理 | JSON 解析失败或校验失败 → 备份坏档到 `ltkp.save.corrupt.<ts>` → 使用默认存档 |
| 保存时机 | 变更后 `markDirty()`，节流 500ms；`wx.onHide`/结算等关键节点 `flush()` |

### 1.2 结构示例

```json
{
  "version": 1,
  "profile": { "uid": "guest_ab12cd34", "nickname": "酷跑玩家", "avatarUrl": "", "isGuest": true, "createdAt": 1760000000000 },
  "currency": { "gold": 0, "diamond": 0 },
  "inventory": { "magnet": 2, "revive": 1 },
  "characters": { "unlocked": ["runner_default"], "levels": { "runner_default": 1 }, "selected": "runner_default" },
  "welfare": { "lastSignInDate": "", "signInCycleDay": 0, "signInHistory": [] },
  "tasks": {
    "daily":  { "date": "2026-10-04", "progress": { "daily.run3": 1 }, "claimed": [] },
    "weekly": { "date": "2026-W40", "progress": {}, "claimed": [] }
  },
  "achievements": { "progress": { "ach.run10": 3 }, "claimed": [] },
  "shop": { "dailyBought": { "gold_1000": 1 }, "dailyRefreshDate": "2026-10-04", "adClaimed": {} },
  "activities": { "claimed": { "act_login": [0] }, "progress": { "act_login": 2 } },
  "stats": { "runs": 3, "bestScore": 1500, "totalDistance": 1200, "totalCoins": 800, "totalDiamonds": 0, "totalPlayMs": 300000, "loginDays": 1 },
  "settings": { "music": true, "sfx": true },
  "flags": { "privacyAccepted": true },
  "updatedAt": 1760000000000
}
```

### 1.3 字段说明与不变量

| 字段 | 不变量 |
| --- | --- |
| currency | 非负整数；`gold`/`diamond` 上限 `9,999,999`（格式化显示 `1.2万`） |
| inventory | 值非负整数；0 时不强制删除键 |
| characters.unlocked | 至少包含默认角色；`selected` 必须已解锁 |
| welfare.signInHistory | 按日期去重，最多保留 90 条（FIFO 裁剪） |
| tasks.*.date | 与当前游戏日不一致时先重置再使用 |
| stats | 只增不减（除重置存档） |
| flags | 只存简单值（boolean/number/string）；约定的键：`pendingBuff.<buffId>`（数字，菜单中使用跑酷增益道具后的待生效次数） |

## 2. 时间与重置规则

| 概念 | 规则 |
| --- | --- |
| 时间源 | `IClock.now()`，默认 `Date.now`，测试可注入 |
| 游戏日 gameDay | `dateString(now - dailyResetHour 小时)`；默认 `dailyResetHour = 0` |
| 每日重置范围 | 商店限购、广告免费次数、每日任务、签到日判断、每日免费奖励 |
| 每周重置 | 每周一 `weekKey` 变化时重置每周任务（`YYYY-Www`） |
| 跨天检测 | `GameContext.refreshDaily()` 在启动、`wx.onShow`、面板打开前调用；检测到游戏日变化时 emit `day.changed` 并触发各服务重置 |
| 活动时间 | `ActivityConfig.startTime/endTime` 为本地时间字符串 `YYYY-MM-DD HH:mm`，进行比较时用 `clock` |

## 3. 配置表（assets/resources/config/*.json）

所有表均为顶层 JSON 数组，`id` 全表唯一。加载后由 `validateConfigs()` 做结构与引用校验，任何错误在控制台输出可读信息并在开发模式抛错。

### 3.1 app.json（AppConfig，单对象）

```json
{
  "version": "0.1.0",
  "cloudEnvId": "",
  "dailyResetHour": 0,
  "weeklyResetWeekday": 1,
  "debug": true,
  "privacyPolicy": "欢迎游玩《雷霆酷跑》...（全文）",
  "userAgreement": "用户协议全文...",
  "contact": { "qq": "123456", "wechat": "ltkp_service", "email": "" }
}
```

说明：`cloudEnvId` 为空时平台进入本地模式（LocalPlatformAdapter）；S10 填入云环境后启用云能力。

### 3.2 items.json（ItemConfig[]）

```json
[
  { "id": "magnet", "name": "磁铁", "desc": "开局携带，10 秒内自动吸附金币。", "icon": "images/items/magnet", "type": "consumable", "quality": 3, "stackable": true, "useEffect": { "kind": "runBuff", "buffId": "magnet" }, "useTargets": ["menu"] },
  { "id": "revive", "name": "复活币", "desc": "局内死亡后可复活一次。", "icon": "images/items/revive", "type": "consumable", "quality": 4, "stackable": true, "useEffect": { "kind": "runBuff", "buffId": "revive" }, "useTargets": ["run"] },
  { "id": "char_shard_lin", "name": "林小满碎片", "desc": "集齐 10 个可解锁角色「林小满」。", "icon": "images/items/char_shard_lin", "type": "material", "quality": 4, "stackable": true }
]
```

`quality` 1–5 对应白/绿/蓝/紫/金，仅影响边框颜色。

### 3.4 shop.json（ShopGoodsConfig[]）

```json
[
  { "id": "free_gold_ad", "tab": "gold", "name": "免费金币", "desc": "看广告得 200 金币", "icon": "images/ui/shop_free_gold", "price": null, "viaAd": true, "gain": { "gold": 200 }, "dailyLimit": 3, "order": 1, "tag": "免费" },
  { "id": "gold_1000", "tab": "gold", "name": "金币袋", "desc": "1000 金币", "icon": "images/ui/shop_gold_s", "price": { "currency": "diamond", "amount": 10 }, "gain": { "gold": 1000 }, "order": 2 },
  { "id": "recharge_6", "tab": "diamond", "name": "60 钻石", "desc": "充值获得 60 钻石", "icon": "images/ui/shop_diamond_s", "price": { "currency": "CNY", "amount": 600 }, "productId": "ltkp.diamond.60", "gain": { "diamond": 60 }, "iosVisible": false, "order": 5 }
]
```

- `price.currency = "CNY"` 时金额单位为分（600 = 6 元），`buy()` 返回 `needPay`，UI 调 `platform.pay()` 成功后调用 `claimPay(goodsId)` 发货；`iosVisible=false` 时 iOS 端隐藏。
- `viaAd=true` 的商品由 UI 拉起激励视频，成功回调后调用 `shop.claimAd(goodsId)`；受 `dailyLimit` 限制；计入 `shop.adClaimed`。
- 普通商品购买计入 `shop.dailyBought`，每日重置。

### 3.5 tasks.json（TaskConfig[]）

```json
[
  { "id": "daily.run3", "type": "daily", "name": "跑 3 局", "desc": "任意模式完成 3 局跑酷", "metric": "run.count", "target": 3, "reward": { "gold": 200, "items": [{ "id": "magnet", "count": 1 }] }, "link": "run", "order": 1 },
  { "id": "weekly.distance2000", "type": "weekly", "name": "本周奔跑 2000 米", "desc": "累计跑动距离达 2000 米", "metric": "run.distance", "target": 2000, "reward": { "diamond": 20 }, "link": "run", "order": 1 }
]
```

`metric` 取值：`run.count` / `run.distance` / `run.score.single` / `run.coins.total` / `run.diamonds.total` / `login.days` / `shop.buy.count` / `character.upgrade.count`。
进步规则：除 `run.score.single` 取单局最高值外，其余累加。

### 3.9 run.json（RunConfig[]）

```json
[
  {
    "mode": "classic",
    "name": "经典模式",
    "settle": { "coinsToGold": 1, "scoreToGoldDivisor": 10, "diamondEveryCoins": 500 },
    "revive": { "adPerRun": 1 },
    "buffs": {
      "magnet": { "name": "磁铁", "desc": "10 秒内自动吸附金币", "durationSec": 10 },
      "revive": { "name": "复活", "desc": "死亡后原地复活一次", "count": 1 }
    }
  }
]
```

结算公式（`core/gameplay/Settlement.ts`）：
`gold = floor(result.coins * coinsToGold) + floor(result.score / scoreToGoldDivisor)`；
`diamond = result.diamonds + floor(result.coins / diamondEveryCoins)`；
奖励翻倍 = 基础奖励 × 2（广告回调成功后发放差额或整体替换，UI 只发一次）。

## 4. 红点规则（RedDotKey）

| key | 点亮条件 | 计算来源 |
| --- | --- | --- |
| menu.tasks | 存在可领取的每日/每周任务 | TaskService.hasClaimable() |
| menu.welfare | 今日未签到 | WelfareService.signInState().todaySigned === false |
| menu.achievements | 存在可领取成就 | AchievementService.hasClaimable() |
| menu.activities | 存在可领取里程碑或时间窗内新活动 | ActivityService.hasClaimable() |
| menu.characters | 存在可解锁角色（资源足够）或可升级角色（资源足够） | CharacterService |
| menu.shop | 存在当日未领完的广告免费商品 | ShopService |

红点在相关事件（currency/task/welfare/... changed 与 `day.changed`）后重新计算并 emit `reddot.changed`。UI 通过 `RedDots.bind(node, key)` 订阅显示。

## 5. 存储与键名规范

| 键 | 内容 |
| --- | --- |
| `ltkp.save.v1` | 玩家存档 JSON |
| `ltkp.save.corrupt.<ts>` | 损坏存档备份 |
| `ltkp.settings` | 预留（当前设置存于存档内） |

禁止在业务代码中直接拼接存储键，统一由 SaveRepository/Storage 常量提供。
