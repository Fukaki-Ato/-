## 1. VAL-05：明确身份与资产保留边界

| 对象 | 实际身份/保存位置 | 清理、换环境或重启的含义 |
| --- | --- | --- |
| 档案昵称、头像、10 位 ID | 当前浏览器同源存储；ID 不是认证凭据或全服唯一号 | 清除存储可能重建；不自动跨设备同步 |
| 可花余额与导入游标 | 本机 canonical 钱包；不是服务器权威余额 | 清除本机记录无法可靠恢复已花余额；只保留 cookie 时，历史累计奖励可能重新导入，不能把它当服务端真实余额恢复 |
| 榜单游客名/成绩 | `tr_lb` cookie 对应服务器 token hash 与 SQLite 记录 | 与本机昵称不同；丢 cookie 不等于服务器删除旧成绩，但当前浏览器可能失去对应身份 |
| 任务累计奖励/任务身份 | `tr_mission_session` 对应的服务端用户；快照 `rewardLedgerId` 为该用户 ID | 与榜单 cookie、本机 ID 分离；cookie 更换而本机存储保留时，本机余额仍在，后续按新的账本身份导入 |
| 页面排位资格/榜单票据 | `tr_rank_session` 与进程内资格/挑战表 | 重启会影响当前页面资格/票据，不能等同于榜单数据库丢失 |

依据：`core/profile/playerProfile.ts:115–138`；`server/http-protocol.mjs` 的 cookie；`server/store.mjs` 的游客名；`apps/server/src/http.mjs:175–186`、`mission-service.mjs:155`；进度钱包的 ledger 高水位。

UI 新增简短本机/榜单/刷新说明，共享自绘 ID 标签同步更正。源码中“本项目没有后端”的旧注释也修为“档案 ID 不绑定任务/榜单身份”。这些说明描述现有边界，不承诺找回账户或新增云存档。
