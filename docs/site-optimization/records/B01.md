## 7. UX-03：模态范围与返回焦点

**来源**：A4/E12/V1；原观察中 Shift+Tab 可进入背后设置滑条。

**产物**：档案内 Tab/Shift+Tab 首尾循环；背景 `inert`，退出恢复之前的 inert 值后再恢复入口焦点；保留 Escape 阻断冒泡。重复清理不会再次恢复旧背景状态。

**验收依据**：回归覆盖初始焦点、首尾循环、保留已经 inert 的其他背景、关闭返回设置入口。真实浏览器中 Shift+Tab 到最后一个昵称，Tab 回关闭按钮；背景滑条拒绝聚焦；Escape 只关档案，焦点返回“打开玩家档案”，随后设置仍可正常返回大厅。390×844、320×568 截图已读取，无横向溢出，见 E03。

**边界**：未进行真实读屏软件语音验收，不将程序化焦点断言等同于读屏听感。

<a id="ux-04"></a>
## 8. UX-04：重建任务列表后的操作上下文

**来源**：A4/E13；领取会整体重建任务列表。

**产物**：按周期、周期 ID、任务 ID 保留焦点上下文；领取中/已领取使用可聚焦任务卡，失败回到可重试领取按钮；用户已移到 tabs/refresh 时不抢回。刷新按钮保留键盘位置，用 `aria-disabled` 表达忙碌并在请求入口拦截重复调用；领取状态带任务名。

**验收依据**：单测覆盖成功、失败、主动移焦、重复刷新与晚返回。浏览器真实键盘领取后焦点留在任务卡；用户按 Tab 到刷新后，即使请求失败也不抢走焦点，见 E01/E04。浏览器任务数据由明确的合成 API 提供，只验证客户端交互，不宣称真实服务已发奖。

<a id="ux-05"></a>
## 9. UX-05：忙碌期间到期的同步请求

**来源**：A4/T2/E13；原周期定时器在 busy 时返回，结束领取只 render，可能失去下一次周期同步。

**产物**：定时器到期记录待同步状态；领取成功或失败后串行执行一次加载，加载成功安排下一定时器。失败显示手动重试，不自动循环；销毁后晚返回不绘制或重新加载。

**验收依据**：九项新增测试覆盖两种领取结果、一次补同步、定时器重设、同步失败后停止、销毁/晚返回及焦点。受控浏览器时钟跨过到期点时，未完成领取期间 GET 数不变；领取以合成 409 结束后恰补一次加载，显示新周期且焦点回到每日 tab，见 E01/E04。

**边界**：未靠真实午夜等待验证；两种结果与清理时序由聚焦测试控制，浏览器只验证代表性动态链路。
