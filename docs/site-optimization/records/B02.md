## 5. VAL-02：购买提交边界

`EconomyStore` 增加游戏层可选的同步事务能力；Web 进度钱包提供具体实现。`buyOffer` 与多币种 `spend` 在草稿中运算，一次 canonical JSON 写入承载余额、物品、限购与装备。外层事务传入的草稿不再次提交，拒绝或中途异常不会落入部分写入。
