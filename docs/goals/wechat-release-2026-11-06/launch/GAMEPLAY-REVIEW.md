**完整简介**

在海滨跑道上躲避障碍、收集金币和补给，体验不同角色的技能。左右滑动切换车道，上滑跳跃、下滑滑铲，技能就绪后双击屏幕释放。完成每日、每周任务与免费福利手册章节，领取游戏内金币、钻石、钥匙或角色碎片；在商店按明确报价兑换资源、解锁角色，到仓库查看拥有内容，在角色页保存出战、设置页选择主题。挑战首次拾取金币之前的距离与分数，查看全服榜单和个人纪录。余额、奖励、兑换和入榜结果以云端确认为准。

本版没有充值/现金支付、广告、现金奖励、抽奖或昵称UGC上传；XP养成、非默认皮肤、活动与好友竞赛等未接能力不在首发介绍内。配置存在 `lootTables`、XP卡或 `status: live` 本身不表示对应玩法已开放；实际商店会禁用未接用途的商品。

## 按实际WX大厅导航体验

大厅中部可上下拖动，底部“开始酷跑”固定；右上“设置”，中部为“角色 / 商店 / 仓库 / 任务 / 免费福利手册 / 榜单”。页面内用“返回”回到上一级；手机操作不依赖键盘。

| 路径与动作 | 应核对的真实结果（当前均待云/微信设备验收） |
| --- | --- |
| 启动→大厅→角色→选择已拥有角色出战→开始跑酷（或大厅“开始酷跑”） | 当前出战与拥有状态正确；保存后下一局使用所选角色。未拥有者不能直接出战，不要求审核者购买现金服务。 |
| 跑局：左/右滑换道，上滑跳、下滑铲；双击屏幕 | HUD显示生命、里程/分数、采集、增益及技能冷却/积攒；技能须满足角色条件。技能/吸币等产生的首次实际金币入账同样终止首币前记录。 |
| 跑至死亡→结算→返回大厅 / 再跑一次 | 等云端确认，核对服务器钱包增加一次；“本局采集金币”不是到账证明。上传失败用“重试上传”发送原票据/回放；等待时不可离页，失败后离开有放弃未确认奖励提示。 |
| 跑局→左下“结束本局”→结算 | 主动结束可同步合法收入；达到当前10秒有效局门槛才计任务/手册进度，主动结束不入排行榜。另完成死亡局核对入榜。 |
| 大厅→任务→每日任务 / 每周任务→达标后领取→返回 | 日周周期按北京时间，进度来自权威回放；金币进入统一钱包，钥匙/碎片进入仓库；刷新/重进不重复发奖。未达标不能领取。 |
| 大厅→免费福利手册→完成并领取章节 | 四章免费，后续章在前章已领取后解锁；奖励与任务共用钱包/库存，无付费手册。 |
| 大厅→商店→角色 / 兑换→报价→确认购买→仓库 | 只消耗游戏内资源、确定性授予，不抽奖。可体验钥匙/钻石换金币、金币买碎片或角色、碎片解锁/回收；以实时可用报价、余额与限购为准。余额不足/未开放应禁用；取消确认不扣款。 |
| 兑换结果不明→重试或刷新；必要时重进商店 | 本机保存原 `offerId/requestId/catalogVersion`，核对原交易；服务端回执确保同请求不重复扣款。恢复后检查余额/拥有读回，不能通过清缓存模拟成功。 |
| 大厅→仓库→已拥有角色出战；大厅→设置→选择主题→下一局；退出重进 | 仓库与角色页共用云拥有/偏好，主题保存并用于跑局；重进读回服务器选择。主题卡是配色预览，不是跑局截图。 |
| 大厅→榜单（或已确认结算→查看榜单）→刷新 | 看前4展示、前50及本人名次；榜名为派生“跑者-…”，非微信昵称。榜单规则见下，不与本局总里程混淆。 |

## 首次金币前排名规则

首次实际拾取金币**入账前**冻结当时距离和分数；若直到死亡未拾币，取结束时记录。之后继续跑得的里程/总分不延长此纪录。服务器重放合法死亡局、按每玩家最佳记录入榜；距离高者优先，同距离比分数，同距离同分按先取得有效改进的顺序。主动结束、调试/测试局、未取到云票据或校验失败局不入榜；云账户取票失败的本地练习局也不计云奖励/任务。
