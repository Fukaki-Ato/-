# 05 平台适配与云开发

## 1. 适配层设计

`IPlatformAdapter`（见 contracts.ts）隔离宿主差异，两种实现：

| 实现 | 触发条件 | 特性 |
| --- | --- | --- |
| LocalPlatformAdapter | `cloudEnvId` 为空或 `typeof wx === 'undefined'` | 游客登录（uid 持久化）、内存/本地存储、广告模拟（可配置成功/取消）、分享仅日志、支付 unsupported、云为本地模拟（排行榜生成假数据 + 写入本机） |
| WechatPlatformAdapter（S10） | 微信小游戏环境 | wx 登录、wx 云开发、激励视频、分享、震动、Android 米大师支付、隐私授权 |

Boot 选择逻辑：`typeof wx !== 'undefined' && wx.cloud && appConfig.cloudEnvId ? Wechat : Local`。
开发期通过 `app.json.debug + flags` 可强制 Local。

## 2. 存储策略

| 环境 | 实现 | 键前缀 |
| --- | --- | --- |
| 微信 | `wx.setStorageSync/getStorageSync` | 原样使用 `ltkp.*` |
| 浏览器预览 | `localStorage` | 同 |
| Node 测试 | 内存 Map | 同 |

存档同步（S10 可选开启）：本地为权威，登录后拉取云端 `updatedAt` 更晚的存档时提示"发现云存档，是否覆盖本地"；上传在 `flush()` 节流后异步执行，失败不阻塞。

## 3. 登录流程

```
Boot → platform.login():
  微信:
    1) wx.login() 取 code
    2) 调用云函数 login（code 换 openid，创建/读取 players 记录）
    3) 返回 { uid=openid, nickname, avatarUrl }
    4) 昵称/头像授权：使用官方头像昵称填写能力；拒绝则用默认"酷跑玩家"+ 默认头像
  失败降级: 生成/复用本地游客 uid（isGuest=true），提示"游客模式"
Local: 首次生成 guest_<random> 并持久化
```

## 4. 云开发设计（S10 实施）

### 4.1 集合

| 集合 | 字段 | 说明 |
| --- | --- | --- |
| players | `_openid, nickname, avatarUrl, bestScore, updatedAt, createdAt` | 玩家档案与最佳成绩 |
| saves | `_openid, save(JSON), version, updatedAt` | 云存档（可选功能） |
| scores | `_openid, nickname, avatarUrl, score, distance, mode, updatedAt` | 每局提交（可按 `updatedAt` 只保留最佳） |

索引：`scores.score` 降序；`saves._openid` 唯一建议。

### 4.2 云函数

| 函数 | 入参 | 返回 | 说明 |
| --- | --- | --- | --- |
| login | 无（取 context OPENID） | `{ uid, nickname, avatarUrl, bestScore }` | openid 初始化/返回档案 |
| syncSave | `{ action:'upload', save, version, updatedAt }` 或 `{ action:'download' }` | `{ ok, serverUpdatedAt }` / `{ ok, save, version, updatedAt }` | 云端版本时间戳比较，防覆盖新档；下载无档时 `save=null`（S10 实现） |
| submitScore | `{ score, distance, mode, nickname, avatarUrl }` | `{ ok, bestScore, rank }` | 写 scores + 更新 players.bestScore |
| getLeaderboard | `{ board: 'global', top: 50 }` | `{ list: [{rank,uid,nickname,avatarUrl,score}], me }` | 世界榜；好友榜走开放数据域（见 4.3） |

云函数目录 `cloudfunctions/<name>/index.js` + `package.json`（wx-server-sdk），公共逻辑放 `cloudfunctions/common`。

### 4.3 好友排行榜（开放数据域）

- 目录 `assets/openDataContext/`（独立 JS 工程，微信开放数据域限制），通过 `wx.getFriendCloudStorage` 读取托管数据。
- 主域在提交成绩时调用 `wx.setUserCloudStorage` 写入 KV：`bestScore`。
- 通信：主域 `postMessage({type:'render'|'hide'})`，开放域在共享画布上绘制好友榜；主域只做占位与遮罩。
- 本地/编辑器环境返回空列表，UI 显示"暂无好友数据"。
- S10 现状：开放数据域代码（`assets/openDataContext/index.js`）与主域桥（`WechatFriendRank`）已就绪，构建后执行 `npm run wechat:opendata` 写入产物；排行榜面板尚未消费共享画布，微信端好友页签暂降级为世界榜（后续可用引擎 `SubContextView` 接入，见 docs/08 §4.5 与 S10 报告）。

## 5. 广告（激励视频）

| 广告位 AdPlacement | 触发场景 | 失败/取消处理 |
| --- | --- | --- |
| settlement.double | 结算双倍领取 | Toast"未看完广告"，按钮恢复可点 |
| shop.free.gold | 商店广告免费商品 | 同上，不发奖 |
| welfare.daily | 福利每日免费奖励 | 同上 |
| run.revive（预留） | 局内复活（由玩法调用） | 同 |

实现：`wx.createRewardedVideoAd({ adUnitId })`，每个 placement 一个实例并缓存；`show()` 包装为 Promise；onError 预加载重试；未配置 adUnitId 时走 Local 模拟（可配置成交付/取消）。广告位 ID 存 `app.json` 扩展字段（S10 增加 `adUnits`）。

## 6. 支付

- Android：`wx.requestMidasPayment`（米大师），商品 `productId` 由 `shop.json` 配置，成功后由 `RewardService` 发放对应 `gain`。
- iOS：虚拟支付受限，所有 `price.currency = 'CNY'` 商品在 iOS 隐藏（`iosVisible` 规则），仅展示可兑换页签。
- 支付回调以米大师服务端校验为准（S10 文档给出最小可用方案与后续加固说明）。

## 7. 分享与合规

- 分享：启用 `wx.showShareMenu({withShareTicket:true})`；`wx.onShareAppMessage` 返回统一文案与截图；结算页提供"炫耀一下"按钮主动分享。
- 隐私：`wx.getPrivacySetting` + `wx.onNeedPrivacyAuthorization`（基础库支持时）实现授权弹窗；未同意前不读取任何用户信息、不调用登录；隐私政策/用户协议文本来自 `app.json`（正式内容由用户替换）。
- 防沉迷/实名：接入微信平台提供的能力（如需要），保留 `platform` 扩展点，不在本次范围实现细节。
- 合规检查清单（S10）：隐私弹窗、用户协议、未成年人提示、内容合规文案、无外链、无诱导分享。
