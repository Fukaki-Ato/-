# Brief 5 — 失重图书馆 (library)

> 场景制作总纲。目标读者：实现该场景的 LLM / 工程师。所有"最低数量"都是**地板不是目标**，按 grandeur & fidelity 标准往密了做。结构对标 docs/stormspire-brief.md（唯一质量基准模板）。
> 对接点：`config/themes.json` 新增主题条目（`scenery: "library"`）+ `packages/game/src/render/library/` 新目录（仿 `render/stormspire/`：InstancedMesh、LOOP=240m 循环回收、确定性 `rnd`、单文件 ≤300 行）+ `render/sceneryProps.ts` 的 `SCENERY_SETS` 注册。
> 种子出处：docs/scene-ideas-backlog.md 备选 3。种子创意四件：书页风暴（千枚片状粒子）、旋转书架旋转门、悬索书梯垂直通道、局部反重力区（翻转重力跑天花板——**唯一需要 sim 层支持的大项，全部压在 Phase B，§11.2 写清 sim 前置改动**）。

## 0. 一句话概念

墨海之上悬着一座"缄默书城"：万卷书塔倒映在墨色的海面里，千页纸风暴永远绕城盘旋。你不再看雷——你在书脊峡谷与阅览长桌之间疾奔，从旋转书架的门缝里钻过，在倒悬书阁的天花板上跑完整段反重力区，把最后一册借出的书送回万卷塔。

气质三词：**缄默、纸感、倒转的庄严。**

与雷脊的差异化承诺：stormspire 是"外放的狂暴"（闪电/雨/巨兽），library 是"内收的静谧"（无雷无雨，全部动效来自纸、墨与烛光——页面翻滚代替雨，墨代替云海，灯笼代替信标）。

## 1. 世界观

### 1.1 文明：誊经人（The Scriptorium）
- 他们把整座图书馆抬离了地面：书塔一根根锚定在墨海上空（塔基挂着黄铜浮锚链），靠"阅读产生的重量"对抗墨海的浮力——**书读得越透，塔浮得越高**。
- 蜡封章是他们的法器：每一册誊完的书都要盖一枚蜡封章，章纹即"这段意义已被锚定"。场景里反复出现的圆形章纹就是族徽。
- 万卷塔（the Codex Spire）是总库：所有书的母本所在，塔身 260m+，是这座城的天际线锚点。

### 1.2 陨落：墨污之夜（The Inkblot）
- 某夜一册"原典"被墨海浸透——墨开始涨潮，字迹溶解，读者一夜散尽。塔群没有坠落（浮锚链还在），但整座城陷入了永远的静默。
- 证据链（场景里要能读出来）：万卷塔顶的双坡顶被"掀开"成三片悬浮碎块仍在公转；大量书塔呈"缺书层"（整层书脊被抽走、露出深色内腔）；蜡封拱门的圆章多数倒扣或跌落半埋；**灯笼还亮着**——缮写院的守护咒没有失效，这座城在等人回来。

### 1.3 玩家身份：还书人（book runner）
- 玩家抱着最后一册借出的书奔跑：沿书脊长桥穿过书城，捡拾散落的烛光书签（对应现有金币层），在墨潮再次上涨前把它送回万卷塔。
- 叙事只要氛围支撑：开场镜头从墨海之下仰拍万卷塔剪影，一阵书页风暴掠过镜头，拉起进起跑台。

派生（调色板内插值，不出圈，同 stormspire/palette.ts 的做法）：页尘白 `#F4ECD9`（翻页波亮带）、墨雾 `#39445C`（墨青×陈纸，雾带/墨团）、纸影深 `#8F7C5C`（层板阴影面）。

## 3. 地形系统

### 3.1 墨海（对应 stormspire 的云海）
- 赛道地面即"书脊长桥"：三车道读作一整幅摊开的长卷纸面（主题 `groundColor` 配陈纸米暗档 `#D9C7A0`，ground 纹理只管明暗、色调交给 groundColor——trackVisuals.ts:47 注释的既定口径），桥两侧就是墨海。
- 墨海表现：桥面两侧各叠两层异速滚动的墨斑纹理平面（38×250m，抄 stormspire/atmosphere.ts:52-82 的云海条配方，色改墨青/墨渊，第二层亮层给微弱烛光反光点）。
- 墨海里偶有金色反射碎光（灯笼倒影）：墨斑亮层里撒 2% 琥珀像素点，随纹理滚动即可，不做真反射。
- 远处墨面隆起 3~5 处"墨丘"剪影（压扁球，抄 atmosphere.ts:236-267 的近云排配方），当前景层次。

### 3.2 书塔配方（所有塔共用，程序化拼装）
- 塔基：石/木混合基座，高 0.6~1.2m，出挑 0.3m。
- 塔身：4~8 层书架层。每层 = 层板（厚 0.12m，皮革棕）+ 一排书脊（见 3.3）+ 挑檐（厚 0.08m，出挑 0.3m，纸灰褐）。
- 收分：上层整体缩放 0.82~0.92，层心对齐。
- 塔顶：双坡顶（跨×0.3m 高）或平顶+木质塔尖；顶上 0~2 盏灯笼。
- **损毁四态**（按比例混编，禁止全是完好塔）：完好 40% / 缺书层（某整层书脊缺失，露出墨渊色内腔薄板）25% / 歪斜层（某层绕 y 转 ±4~7°）20% / 断顶塌层（顶斜落 15~25° 挂在檐上）15%。
- **三档尺寸**：S（6~10m，1~2 层）；M（12~20m，3~5 层）；L（24~40m，6~8 层 + 灯笼阵 2~4 盏）。

### 3.3 书本拼装配方（单册，全场景复用的最小件）
- 单册 = 一个盒体：宽 0.12~0.24m × 高 0.28~0.42m × 深 0.16~0.28m（长宽高独立随机，禁止等比缩放的同一种书）。
- 装帧色：instanceColor 从 [陈纸米 / 纸灰褐 / 皮革棕 / 蜡封红 / 墨青] 五色取（蜡封红书脊占 8%，做视觉节奏点）；书页侧三面强制陈纸米（书脊色 ≠ 页色，侧看才读得出"这是一本书"）。
- 脊上标签条：30% 的书带一条蜡封红或烛光琥珀短标签（实例化小盒）。
- 立放为主（~92%），随机 8% 斜倚 ±12°；每层书脊间随机留 0~1 个空槽（0.2~0.4m），空槽是"被取走的书"的证据链之一。
- 实例化口径：全部书脊进 InstancedMesh，按 3 个 batch 分（受光 Lambert ×2 + 标签 Basic ×1），单场景 2000+ 册。

### 3.4 布景分层（沿用 sceneryProps 三排填深度的传统，sceneryProps.ts:4-7）
- near（|x| 4.6~7m）：阅览长桌、散书、灯柱、书栏——近景密度主层，走 rhythmZ 疏密节奏（bridge.ts:38-49 的 240m 切 8 段 ×0.7/×1.45 公式直接复用）。
- mid（|x| 8~16m）：S/M 档书塔、摊开书岛、旋转书架装饰座。
- far（|x| 17~30m）：L 档书塔、墨丘、万卷塔剪影层。

### 3.5 墨瀑（6 条地板）
- 表现：UV 滚动的墨色丝带 shader（双面），体色墨青 + 2% 烛光金屑闪点（DataTexture 竖纹滚动，抄 islands.ts 的瀑布竖纹做法）；落点墨雾团呼吸（0.35→0.55 opacity）。
- 两种宽度：窄瀑 1.5~2.5m（装饰，书岛边缘 4 处），宽瀑 4~6m（L 塔旁 2 处，垂进墨海）。

### 3.6 反重力书阁（Phase A 视觉 / Phase B sim，详见 §11.2）
- 形制：赛道上方 4.6m 一整段倒挂书阁——吊顶层板 + 倒挂书架（书脊朝下，用 3.3 配方倒置）+ 入口"倒悬漩涡"标记环（烛光琥珀发光环，径 6m，斜挂 15°）+ 出口章纹门。
- Phase A：纯视觉隧道（玩家照常地面跑，头顶的倒挂书城是"接下来会有的事"的预告）。
- Phase B：sim 翻转重力，入口环即翻转触发器（§11.2 B-1~B-8）。

## 4. 建筑资产目录（每件 = 数量地板 / 形制 / 材质 / 损毁态 / 动效 / 玩法功能）

### 4.1 万卷塔（the Codex Spire）×1 —— 场景主地标
- **形制**：八角收分书塔，底径 26m 收至顶径 9m；**叙事高 260m+，Phase A 可见几何 ≤60m**——对齐雷脊先例（brief 写 300m+、实码 TOWER_H=58，stormspire/tower.ts:26）：260m 实体在 far 排 |x| 17~30 下，塔顶径向距离 √(30²+260²)≈262m，超 camera far 160（runnerScene.ts:90）且沉在雾视距 120 之外，必被裁；可见段做层带条纹剪影（每 3.2m 一层，明暗交替，不逐书建模）；每 32m 一圈出挑回廊 + 灯笼；塔基是一座摊开的巨型对开本台座（跨度 ~60m）；塔顶双坡顶被掀成三片悬浮碎块（各 6~10m，绕塔轴缓慢公转 0.05~0.1 rad/s，微微倾斜）。
- **塔位与可见性校核**：×2 座沿 LOOP 错 z（对齐 tower.ts:22-25 双塔做法）：A `x=-28, z=-60`（最近径向距 ≈66m，雾窗内可见段全身入画）；B `x=30, z=-175`（随 LOOP 滚动入画，z≈0 最近时径向距 ≈30m，仰视压迫感最强）；「远处塔群天际线」由远景剪影带承担（对齐 stormspire/skyline.ts 做法，不堆真几何）。
- **材质**：皮革棕塔身 + 陈纸米层带 + 蜡封红封条竖纹（4 条，自底螺旋向上）+ 烛光琥珀灯笼点。
- **动效**：整体极缓摇曳（±0.1°，周期 26s）；三片顶盖碎块公转；灯笼按层带错相呼吸（周期 3~5s）。
- **玩法**：Act 3 终点段视觉锚 + Phase B 登塔书梯的墙面提供者（同 stormspire 塔的地位）。

### 4.2 书塔（S/M/L 三档）—— 40+ 座地板，实例化
- 形制/损毁按 §3.2 配方；每档 1 套几何 + InstancedMesh；书脊另列（§3.3，2000+ 册）。
- 玩法：无（纯侧景纵深主体）；near 排由书塔基座延伸出"书脊矮栏"与跑道对话（同 stormspire bridge.ts 栏石做法：12% 缺损 + 歪斜）。

### 4.3 摊开书岛（folio island）—— 8~12 座，中景
- 形制：巨型摊开对开本，8~20m，书面微微上翘（页缘波状位移，几何级一次成型），中央书沟深 0.4m；下方倒挂"书山钟乳"3~6 枚（书堆锥体，实例化）+ 1~2 条垂到墨海的黄铜锚链。
- 损毁态：页角残缺 30% / 半合拢（右半页上折 30°）20% / 完好 50%。
- 玩法：无；墨海上的浮空层次 + 纸鹤群栖息点。

### 4.4 旋转书架（revolving shelf）—— 场景签名物
- **形制**：高 3.2m 四翼十字书架，单翼宽 2.2m × 厚 0.5m，翼面塞满书脊（§3.3 配方缩微版）；中柱黄铜（径 0.22m，金属 envMap）；底座圆盘径 3m。
- **数量**：装饰座 6（mid 排，缓慢自转 0.15~0.3 rad/s，相邻座转速/方向错开）+ 障碍位（复用 `obs_adwall` 满格墙判定，Phase A 皮肤=静态四翼书架正对玩家的一翼，见 §11.1 步骤 7）。
- **动效**：装饰座持续自转；障碍座 Phase A 静态（判定口径零改动），Phase B 升级为真旋转门（rotor gate，§11.2 B-10）。
- **玩法**：Phase A 满格墙=必须换道；Phase B 翼缝时机障碍（转缝对位才能过）。

### 4.5 悬索书梯（suspension ladder）—— 垂直通道签名物
- **形制**：两条黄铜悬链（径 0.08m）挂 1.2×0.4m 书板踏级（级距 0.5m）。三种段型：①横跨跑道的拱段（跨 12~16m，拱下净高 4.5m，跑得过）每 240m ×2；②从两侧书塔层檐垂向墨海的长梯段（12~18m，装饰）每 240m ×4；③连塔横梯（mid-far 之间，斜 20~35°，6~10 条远景）。
- **动效**：悬链 0.5% scaleY 呼吸；随机 2 枚踏级轻晃（rx ±0.04，3s 周期，确定性相位）。
- **玩法**：Phase A 纯视觉（拱=过场画框）；Phase B 接真海拔剖面后成为垂直通道（§11.2 B-9，单列后置项）。

### 4.6 阅览长桌排（reading row）—— near 排主体，24+ 张
- 形制：桌面 3.6×1.2×0.08m、高 0.75m，四腿；桌面上一盏铜灯（琥珀 Basic 亮头）+ 1~2 本摊开的书（两块斜面三角页）。
- 损毁态：桌面倾斜 8° 20% / 缺一腿 15% / 整桌倒扣 10% / 完好 55%。
- 排布：沿 |x|=5.2 每 8~14m 一桌，吃 rhythmZ 疏密；灯下路面一枚光池（64² 径向渐变 DataTexture，抄 bridge.ts:51-68 配方，opacity 0.15）。
- 玩法：无；近景密度对标 konbini 近景带的公式来源（docs/stormspire-brief.md §Phase A 整改记录）。

### 4.7 蜡封拱门（wax-seal arch）×8
- 形制：跨 8~12m 拱门，楔石实例化；拱心一枚径 1.6m 蜡封圆章（浮雕双环 + 放射章纹，蜡封红 Lambert）；柱础各一摞书堆（3~5 册，§3.3）。
- 三态：完整拱 50% / 半塌拱（一侧拱脚落地成斜坡）30% / 断桩 20%（只剩两脚+坠地半枚圆章）。
- 玩法：视觉框；完整拱净高统一 4.5m 直跑（滑铲净高的压迫感由 high 障碍皮肤承担，别做 2.2m 拱——和 high 皮的可读性会打架）。

### 4.8 灯柱信标（lamp beacon）×16
- 高 3.6m 铜杆（皮革棕暗档）+ 琥珀灯头（Basic ×1.3 HDR，保证过 bloom 阈值 0.82，postfx.ts:21）+ 正下方光池；×16 ⇒ 240m LOOP 内每 ~15m 一根（240÷16，同 titan 魂火灯的校正口径），走 rhythmZ 相位错开。
- 玩法：导航锚点 + 夜景节奏点。

### 4.9 散书与倒伏书堆（near 排填充）
- 散书：路缘带（|x| 4.8~5.8m）每 1.5m 每侧一个随机位、30% 命中，三态：平躺 / 斜倚 / 开面朝上（两页三角板）——240m 一圈 320 位 × 0.3 ≈ 96 册地板。
- 倒伏书堆：书塔脚下的塌落堆（4~8 册错缝叠），每塔 30% 概率。
- 玩法：无；"墨污之夜"的证据链近景。

### 4.10 反重力书阁 ×每 240m 1 段（Phase A 视觉件）
- 形制/动效见 §3.6；吊顶书架全部倒置实例化，入口环烛光琥珀 + 0.5Hz 微光脉动。
- 玩法：Phase A 无；Phase B 翻转触发器（§11.2）。

## 5. 生物（全部独立于玩家运行）

### 5.1 纸鹤（paper cranes）—— 3 群 × 40 = 120 地板
- 形制：折纸几何鹤三件套（身/双翼），翼展 0.8~1.4m；陈纸米 85% + 翼尖蜡封红 15%。
- 行为：参数化群飞（**不是真 boid**——零分配零 O(n²)，观感等价，配方照抄 stormspire/creatures.ts:3-4 的口径）；路径在书塔缝隙间穿行（硬指标：每群路径至少 2 次穿过书塔间缝）。
- 动效：拍翼 1.2s 周期（顶点级或双翼实例对摆），远近距离各一群。

### 5.2 墨渊鲸（ink leviathan）×1
- 形制：160m 级鲸-蛇混合体剪影，只以剪影 + 轮廓光呈现，体侧嵌点状烛光琥珀发光斑（"书虫萤"共生的暗示）；禁给正脸细节。
- 行为：在墨海面下半沉半现地绕大圈巡游，**每分钟至少完整掠过一次**；经过处墨海泛起缓慢波纹（墨斑亮层 offset 扰动一次即可）。

## 7. 光照与后期

- **基础光**（themes.json `lighting` 字段覆盖，runTheme.ts:57-65 消费）：半球光天空 `#B8AE9A`（暖纸顶光弱档）/ 地面 `#241F3D`（墨渊反光），强度 0.9；主光 `#D8C9A8` 强度 1.0。低强度纸感光，明暗对比靠自发光灯笼与雾纵深，不靠硬阴影（微信端无 shadowMap，落影沿用 sceneryProps.ts:88-94 的假投影口径）。

## 8. 赛道叙事（三幕 + 视觉 chunk）

> 现有玩法是 lane + worldZ 平面滚动赛道，障碍 pattern 池**全主题共享**（trackGen 不读主题差异，见 §11.0 事实 3）。本场景的"chunk"因此是**视觉 chunk**：240m LOOP 内书塔原型与近景件的排布轮换 + rhythmZ 八段疏密。难度叙事直接映射全局难度档 `difficulty = floor(z/300)`（trackGen.ts:111）。

### Act 1 — 书脊坊（教学段，0~200m / 难度 0 档）
阅览长桌排开场的平缓起跑：灯柱列队引路、散书与倒伏书堆温柔点缀；障碍只有全局低档池的跳板与滑铲拱；200m 处第一次仰望万卷塔可见段（雾窗内的层带剪影 + 塔顶悬浮碎块，§4.1 塔位校核），第一群纸鹤掠过头顶。

### Act 2 — 书塔巷道（200~600m / 难度 1~2 档）
mid 排书塔最密、疏密节奏最强调的段落：旋转书架装饰座开始出现在两侧自转、悬索书梯拱 ×2 提供过场画框、墨瀑从书岛边缘垂落；全局 pattern 的摆锤在这里被皮肤读作"墨滴黄铜摆锤"，满格墙读作"静态旋转书架"。

### Act 3 — 倒悬书阁与万卷塔（600~900m / 难度 2+ 档，循环）
反重力书阁入口环出现（Phase A：头顶的倒挂书城视觉隧道；Phase B：真翻转重力跑天花板，§11.2）；穿过书阁出口章纹门，万卷塔塔基的对开本台座迎面而来，最后一个蜡封拱门框住塔身剪影，回到 Act 2 起点 chunk 池循环。

### 视觉 chunk 拼装规则
- 240m 一圈切 8 段（每段 30m），奇数段密集（间距 ×0.7）偶数段开阔（×1.45）——rhythmZ 直接复用，各元素类错开 phase，密集段不同类不叠同一 z 窗（bridge.ts:38-49 注释的既定口径）。
- 三幕在 LOOP 内表现为"段型混编权重"：书塔密度 / 书阁段 / 书岛段按 Act 语义布相位，不引入第二套随机系统。
- 确定性约束：渲染层排布全部走 `rnd(i, salt)` 与固定相位；不读 sim、不反写玩法（与 worldBend 同款红线）。

### 11.2 Phase B（sim 前置项——反重力区，唯一 sim 大项）

**前置原则**：sim 层纯逻辑、固定步长、确定性（runnerSim.ts:1-5）；回放/golden/排行榜依赖同 seed 同轨迹。翻转状态必须从 `(distance, seed)` 推导，渲染层只读不反写（与 worldBend.ts:4-6 同款红线）。涉及文件与行号是 2026-11-08 快照，动手前先重读。

- **B-1 区块实体**：TrackGen 增 `zones` 数组与 `zoneAt(z)` 查询；obstacles.json 增 `antigrav` 配置段 `{ lengthM, everyM, fromM, ceilingH }`，读取方式仿 zap 段（trackGen.ts:104-108 读、:194-205 生成循环）。**推荐铺设法**：zone 的 nextZ 先于 pattern 生成注册（同 nextZapZ 模式），ensure() 铺 pattern 时对落进 `[zoneStart, zoneEnd]` 的 vehicle / moving / step 类 cell 跳过——v1 区内只放 low/high/full/hazard 四类，天然规避"倒挂列车"体验验收成本；备选方案是 zone 段完全生成后用 `clearObstacles`（trackGen.ts:261-272）事后软清，实现更少但依赖生成顺序，二选一必须写下决策。无论哪种铺法都必须带**禁铺窗规则**：zone 入口前 12m 与出口后 12m 不铺任何 cell（含 low/high 全部类别）——预注册法里把 `[zStart−12, zStart]` 与 `[zEnd, zEnd+12]` 一并登记、ensure() 落 cell 时跳过；这条是 B-3「入口 12m 净空由 B-1 保证」与 B-8「出口后 12m 落地段净空」的实现出处，滑翔进区的落地段才不会踩到区内 low/high。
- **B-2 状态**：`RunnerState` 增 `flip: 1 | -1` 与 `ceilH: number`（0=不在区内）；`initialRunnerState()`（simTypes.ts:70-79）补初值；每步 step 前由 `zoneAt(distance)` 推导写入。flip 可由 seed+distance 复现，summary()/回放格式不需要新字段；若 golden 快照逐字段对比 state，动手时先跑 tests/golden.test.mjs 确认是否要补字段。
- **B-3 运动学**（movement.ts）：`advanceVertical` 的重力项 `s.vy += this.P.gravity * dt`（:138）改 `* flip`；落地钳制（:140 `y <= floorY`）改双向——flip=1 钳上表面、flip=-1 钳 `y ≥ ceilH`；`supportHeight`（:151-168）v1 不查障碍（区内支撑面恒为天花板平面，B-1 已清走载具/斜坡）；`jump()`（:65-68）改 `vy = jumpVelocity * flip`（倒挂起跳是向地面跃），`slideInput`（:60-63）的 DIVE_VY 反号；滑翔/飞行 buff 与翻转区的相遇规则定为**单向门**：gliding 或 flyT>0 进入区段时按正常重力落地后才翻转（入口 12m 净空由 B-1 保证），实现最简且无空中翻转歧义。
- **B-4 碰撞镜像**（collision.ts）：`hitsRunner`（:74-86）增 flip 上下文——推荐实现：`yEff = ceilH - s.y` 代入现有六类谓词（low `yEff < o.h*0.75`、hazard `yEff < HAZARD_HIT_Y`、high 杆下净空、full 恒判），**零新增障碍类**；RIDE_TOP_EPS 镜像同式。调用侧在 runnerSim.collide()（runnerSim.ts:259-281）构造零分配的镜像视图对象复用。
- **B-5 收集判定**（collect.ts）：身体中心 `s.y + 0.9`（:47）改 `s.y + flip * 0.9`（倒挂时身体垂向下方，中心在 s.y−0.9）；区内金币带 y = `ceilH − 0.65`，由 trackCoins 铺设时带 bandY 参数（trackSky 的 skyY 同款通路）。
- **B-6 事件**：SimEvent 增 `{ type: 'flip'; flip: 1 | -1; ceilH: number }`，渲染/音频据此做翻转过渡（约 0.35s 的镜头滚转 + 音效下潜）；drainEvents 通路不变。
- **B-7 渲染翻转**：avatarRig 倒挂（roll π）、cameraRig 倒挂目标（camY 镜像式 `ceilH − (s.y*0.5+4.6)`，空中分支同理）、footDust 贴天花板、皮肤 emit 的 y 坐标由 entityLayers 统一按 flip 镜像后传入（obstacleSkin 不感知 flip）。
- **B-8 数值地板**：ceilingH = 4.6m（与 flight.heightM 同值，镜头与金币带口径统一）；区长 60~120m；fromM = 600（难度 ≥2 档才出现）；everyM 400~600；出口后 12m 落地段净空。跳跃可达核验：顶点 v²/2g = 13.5²/76 ≈ 2.40m（game.json:11-12），倒挂低障可视顶与地面同口径（h×0.75），可用。
- **B-9 悬索书梯玩法化（单列后置，与反重力解耦）**：真海拔剖面（sim y profile）是独立大项，不在反重力 B-1~B-8 范围内；开做时再立独立设计稿。
- **B-10 旋转门 rotor（小项，与反重力并行）**：obstacles.json 新 def（cls `full` + `rotor: { periodS, gapK }` 字段）或新 cls，`hitsRunner` 增一个确定性分支：`|sin(2π·t/periodS + phase)| ≤ gapK` 时翼缝对位不判负；渲染四翼绕竖轴自转。规模 ≤ 一个谓词分支 + 一个皮肤槽。
- **测试**：tests/runnerSim.test.mjs 增倒挂 fixture（同 seed 断言 flip 轨迹与落点）；collision 镜像谓词表驱动测试；golden 回放回归。
