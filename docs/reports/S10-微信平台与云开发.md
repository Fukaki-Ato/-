## 改动清单

### 新增（`assets/scripts/ui/platform/wechat/`，含 `.meta`）

| 文件 | 用途 |
| --- | --- |
| `WechatTypes.ts` | 微信宿主 API 最小结构化类型；全局 `wx` 唯一直连探测点（`getGlobalWx`）。core 工程（tests 会引用本模块）不加载官方 typings，模块内声明占位保证两套 tsconfig 均可编译 |
| `WechatConfig.ts` | `app.json` 扩展字段读取与清洗（`cloudEnvId/adUnits/pay/share/forceLocal`）+ `AD_PLACEMENTS` 常量 |
| `WechatStorage.ts` | `IStorage` 的 wx 同步存储实现（读写异常吞掉返回安全值） |
| `WechatAdService.ts` | `IAdService` 激励视频：placement→adUnitId、实例缓存、`preload`、`show` Promise 化（`onClose.isEnded` 决定 completed）、`onError` 预加载重试、失败统一 `{completed:false}`；空广告位走 `MockAdService` 保持可测 |
| `WechatCloudService.ts` | `ICloudService`：`wx.cloud.callFunction` 封装（超时 8s/错误 → 安全默认值，不抛 UI）；`login`（契约外附加）；`uploadSave/downloadSave`→`syncSave`；`submitScore`；`getLeaderboard`（friends 降级 world） |
| `WechatPlatformAdapter.ts` | `IPlatformAdapter`（`kind='wechat'`）：云初始化、登录（失败游客 uid 降级 `isGuest=true`）、分享（统一文案/query）、Android 米大师支付（未配置 offerId 或非 Android → `unsupported`）、`setUserCloudStorage`、震动、剪贴板、`onShow/onHide` 生命周期、原生隐私授权扩展方法 |
| `WechatFriendRank.ts` | 主域→开放数据域桥：`render/hide` postMessage（可选任务） |
