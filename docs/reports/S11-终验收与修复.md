## 发现的缺陷与修复（S10 引入）

**缺陷**：`getGlobalWx()`（`assets/scripts/ui/platform/wechat/WechatTypes.ts`）先执行 `const globalWx = wx` 再做 `undefined` 判断。在浏览器/编辑器等非微信环境，裸露引用 `wx` 立即抛 `ReferenceError: wx is not defined`，导致 S10 之后 web 端启动直接进入「启动失败」错误面板。

**根因**：S10 将平台选择逻辑改为启动时调用 `getGlobalWx()`（此前浏览器路径不经过该函数），使问题首次在 web 构建中可达；单测均通过构造参数注入 `wx`，未覆盖裸调用路径。

**修复**：改为先 `typeof wx === 'undefined'` 短路判断再引用；新增 `tests/platform/WechatTypes.test.ts` 覆盖「无 wx 全局返回 null」与「存在 wx 全局返回同一对象」两条回归用例。
