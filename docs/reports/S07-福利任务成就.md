## 关键实现决策

1. **状态一律以服务返回为准**：面板只调用 `welfare.signInState()/dailyFreeAdClaimed()`、`task.list()/hasClaimable` 语义字段（`claimable/claimed`）、`achievement.list()`；行完成态由 `view.claimable || view.claimed` 传入，UI 不自算进度或红点。
2. **防连点**：面板级 `busy` + 按钮 `setInteractable`；签到、领取、一键领取、看广告期间禁用，`finally` 恢复；发货幂等由服务层保证（重复调用返回 `already_claimed`）。
3. **跨天刷新**：`onOpen` 调 `ctx.refreshDaily()`（幂等）并订阅 `day.changed`；服务层 `refreshIfNeeded` 完成重置。
4. **广告异常兜底**：`ad.show()` reject 与 `completed=false` 分别 Toast 且不发奖；`claimDailyFreeAd()` 再次校验限购（服务幂等）。
5. **link 跳转**：`run` → Toast 提示后关闭面板（S08 接入开始跑酷）；`shop`/`character`/`welfare` → `PanelManager.has` 判断后 `open`，未注册 Toast「对应功能开发中」（S06 合并后自动生效）；`none`/缺省 → 提示无跳转。
6. **列表刷新**：`task.changed` 同步触发 `setData` 重建行，同页签刷新保留 `content` 滚动位置；切页签/切类型回到顶部。
7. **代码评审**：reviewer 子代理复核后修复 3 项：广告 `show()` reject 未兜底、行完成态改为服务视图传入、任务列表与「返回」按钮 9px 重叠（列表高度 790→760）。
