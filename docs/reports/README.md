# 子会话完成报告目录

子会话在完成开发后，必须在本目录创建 `SXX-<名称>.md` 报告，格式见 `docs/07-测试与验收标准.md` 第 4 节。

命名示例：

- `S01-工程骨架与核心框架.md`
- `S02-配置表与经济服务.md`
- `S03-进度服务与全局装配.md`
- `S04-UI基座.md`
- `S05-启动与主界面.md`
- `S06-商店仓库角色.md`
- `S07-福利任务成就.md`
- `S08-跑酷接入与结算.md`
- `S09-活动排行榜分享.md`
- `S10-微信平台与云开发.md`

主会话将以报告 + git 提交为依据执行验收。
