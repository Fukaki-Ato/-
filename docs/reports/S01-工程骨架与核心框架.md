## 遗留问题 / 需要人工验证

1. **编辑器版本对齐**：工程当前声明 Cocos Creator 3.8.8 与 `@cocos/creator-types@3.8.8`。若后续安装的是 3.8.6/3.8.7，请执行 `npm install -D @cocos/creator-types@<实际版本>` 并把 `package.json` 的 `creator.version` 改为同一小版本（docs/08 §1）。安装编辑器后需人工冒烟：打开工程 → 编辑 `Main.scene`（S05 提供）→ 预览。
2. **`tsconfig.json` 与 CLI 的兼容处理**：`tsconfig.json` 按规范 `extends ./temp/tsconfig.cocos.json`，该文件由编辑器生成；未装编辑器时 Vite 8（Vitest）加载它的 oxc 转换会报 “Tsconfig not found”。已在 `vitest.config.ts` 显式指定 `tsconfig: './tsconfig.core.json'` 解决，不影响编辑器与 `tsc` 行为。编辑器首次打开生成 `temp/` 后此配置仍成立。
3. **Vite 配置加载警告（非阻塞）**：`package.json` 的 `type: "3d"`（Cocos 规范，不能改为 `module`）导致 Vite 对 `vitest.config.ts` 提示 “ESM syntax in a file loaded as CommonJS”。当前版本仅为警告，`npm run check` 正常通过；如未来 Vite 默认 native loader，可将配置改为 `.mts`（需同步更新 docs/01 目录结构）。
4. 首次 `repo.load()` 在无存档时会立即写入默认档（便于后续服务直接使用）；如需“仅登录后落盘”，S03 装配时可按需调整调用时机（不改接口）。
