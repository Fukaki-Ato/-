## 实现要点

- **活动列表**：`ctx.activity.list()` 渲染 Banner 卡；图片走 `Assets.applySprite` 占位降级；状态标签颜色区分三态；存在可领取里程碑的卡片显示红点；面板标题经 `RedDots.bind(title, 'menu.activities')` 绑定全局红点 key。
- **活动详情**：同面板视图切换，底部主按钮在「返回」/「返回列表」间切换；规则文本经 `TextDialog.show({ title, text: ruleText || desc })`；里程碑行含目标、`x/y`、进度条、奖励文案、领取按钮。
- **领取状态机**（`milestoneButtonState`）：`已领取`（claimed）> `未开始`（upcoming）> `已结束`（ended）> `领取`（active 且 claimable，可点）> `未达成`（active 未达标），由 `ActivityView.status` + `milestone` 派生，UI 不自算进度。
- **领取结果**：`ctx.activity.claim(id, index)` 成功 → `RewardPopup.show(ctx.reward.describe(reward))`；失败按 `FailReason` Toast（`already_claimed`→已领取 / `expired`→活动已结束 / `locked`→活动未开始 / `insufficient`→进度未达成），幂等由服务层保证。
- **排行榜加载**：请求携带自增序号防竞态，`onClose` 使未返回请求失效；加载 `LoadingMask`、空数据 `EmptyState`「暂无数据」、失败 Toast + 重试按钮、`offline` 显示「离线模式」标签；刷新方式取「顶部刷新按钮」（任务允许二选一）。
- **我的最佳成绩**：优先 `LeaderboardResult.me`，缺省回退 `ctx.save.stats.bestScore`（显示「未上榜」）。
- **分享**：设置面板调用 `ctx.platform.share`，不直接触碰 `wx.*`；失败静默 Toast，不阻塞面板。
- **主会话登记指引**（合并后在 `ui/panels/index.ts` 追加）：
  ```ts
  import { ActivitiesPanel } from './ActivitiesPanel';
  import { LeaderboardPanel } from './LeaderboardPanel';
  // registerAllPanels() 内：
  PanelManager.register(PANEL_NAMES.activities, (ctx) => new ActivitiesPanel(ctx));
  PanelManager.register(PANEL_NAMES.leaderboard, (ctx) => new LeaderboardPanel(ctx));
  ```
