## 功能要点

### ShopPanel

- 页签 `gold/diamond/props/special`，每页 `GridList` 渲染 `ctx.shop.list(tab)`；打开时 `ctx.shop.refreshIfNeeded()`，订阅 `shop.changed`/`currency.changed` 刷新。
- 商品卡：图标占位降级、名称、描述、价格（金币/钻石图标+数值、免费、¥x.xx）、限购角标「今日 n/m」、`tag` 标签、售罄/锁定置灰遮罩与原因。
- 购买流程：ConfirmDialog（价格+获得内容）→ `ctx.shop.buy(id)`：
  - `needAd` → LoadingMask + `platform.ad.show('shop.free.gold')`；完成 → `claimAd` → RewardPopup；取消 → Toast「看完视频才能领取」；
  - `needPay` → `platform.pay`；ok → `claimPay` + RewardPopup；cancel/unsupported → 对应 Toast；
  - `ok` → RewardPopup；失败按 reason Toast；`insufficient` 弹「去赚金币/去充值」并切换对应页签。
- iOS 可见性：`kind === 'wechat'` 且本机判断为 iOS 时过滤 `iosVisible=false` 的 CNY 商品。`IPlatformAdapter` 未提供系统信息，`ShopPanel` 内 `isIOSPlatform()` 为本地占位（微信宿主存在时读取 `getSystemInfoSync`，否则 false），含 TODO 待 S10 平台接口替换，未改契约。

### WarehousePanel + ItemDetailPopup

- 数据 `ctx.inventory.all()`（数量为 0 不展示）+ `ctx.config.item()`；配置缺失按 id/占位渲染，不崩溃。
- 品质边框 `Theme.qualityColor`，数量角标 `formatNumber`；订阅 `inventory.changed` 刷新；空态 `EmptyState`。
- 详情弹窗：图标、名称、品质·类型、描述、用途、拥有数量；“使用”按钮三态：
  - 菜单可用（有 effect 且 runBuff 的 `useTargets` 含 `menu`）→「使用」→ `ctx.useItem`；runBuff 成功 Toast「已激活，下局生效」，grant 成功 RewardPopup，unlockCharacter 成功奖励弹窗；
  - 仅 run → 置灰「局内使用」；无 effect（材料）→ 显示「材料」无按钮；
  - 失败按 reason（数量不足/角色已解锁/条件未满足等）。

### CharactersPanel

- 角色卡列表：头像占位、名称、品质边框（选中高亮金框）、状态（使用中 / Lv.x / 未解锁）。
- 详情：立绘占位（品质色框）、名称、品质·等级、描述、速度/跳跃/磁铁/金币加成四行属性（升级前显示 `+成长值` 预览）、费用/锁定原因提示、操作按钮。
- 按钮状态（详情区左右两个按钮）：
  - 未解锁：「解锁」（居中；currency/item 显示费用；item 显示拥有数；condition 显示锁定原因并禁用）；
  - 已解锁：左「使用」（已选时置灰「使用中」）+ 右「升级」（费用 + 等级预览，资源不足禁用并提示；满级时置灰「已满级」）。
- 操作统一走 `ctx.character.unlock/upgrade/select`；成功 Toast + 立绘缩放动效；订阅 `character.changed`/`currency.changed`/`inventory.changed` 刷新。防连点仅针对「同一角色同一操作」300ms，解锁后立即点使用不受影响。
- 红点 `menu.characters` 不在面板内计算。

## 关键实现决策

1. 主题文案与展示辅助集中在 `panelHelpers.ts`，三个面板不重复实现价格/费用/品质/失败原因逻辑。
2. iOS 判断为本地占位函数（`ShopPanel` 内），仅作 CNY 可见性单一实现点，不改 `IPlatformAdapter` 契约，留 S10 TODO。
3. `ItemDetailPopup` 采用框架 `Modal` 外壳独立创建（不注册进 `PanelManager`），避免修改 `ui/panels/index.ts`。
4. 角色详情采用「使用 + 升级」双按钮：未解锁时只显示居中的「解锁」，避免出现“已解锁未选中且未满级时无法选择”的死角；防连点按「操作+角色 id」加 300ms 冷却，解锁后立即点使用不受影响。
5. 配置缺失（道具/角色）走占位展示而不是跳过，符合“占位不崩溃”。
