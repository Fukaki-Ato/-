## 实质改造

牢大重做背心、分腿短裤、肩部和领口连接、脚踝运动袜；保留黄紫篮球身份与原脸部/球类表演。
奶蛙保留黄身体和奶白肚腹，减面并增加眼缘轮廓。阿牛把原本置于头顶的眼部改到正面，
增加红色颈巾与蹄缝。曼波/鲸鱼女仆保留原服饰身份，增加裙褶、下摆随腿权重和鞋部细节，
短裙角色采用较低的回收抬腿，减少裙装穿插。

所有角色有完整核心动作和各自表演动作；新 Run/Idle 为离线实际烘焙。
矩阵/权重/脚底观察修正与回归检查不等于最终目标端美术验收，后续仍需在微信观察连续动作和障碍关系。

## 编辑与来源边界

Blender 中选择骨架，在 NLA 编辑器静音其他 track、启用目标动作；网格、顶点组和动作均可继续编辑。
重建脚本会覆盖任务拥有的同名工程/GLB，手改工程请另存。

原五个输入 GLB 的来源/再发布许可仍未得到补证，由它们派生的改造模型和肖像也保留同一待核实事项。
四名新角色不使用外部模型、贴图或动作；软件工具许可与游戏素材许可分别处理。
源工程不进入微信资源包，只有配置引用的 GLB 和 UI PNG 会被打包。
